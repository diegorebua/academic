# ESlint

## O que é

- ESLint é um linter para o JavaScript e TypeScript: ele lê o código sem executar e aponra problemas com base nas regras.

## Pra que serve

- Pegar bugs comuns antes de rodar: variavel não usada, == no lugar de ===, await esquecido, código que nunca executa.
- Padronizar o código de time: todo mundo segue as mesmas regras (nomes, imports, complexidade)
- Corrigir parte dos problemas com o eslint --fix

## Como funciona

- Transforma o código em uma árvore (AST)
- Cada regra percorre essa árvore procurando um padrão
- Cada problema encontrado vira um aviso (warn) ou um erro (error), conforme a sua configuração (eslint.config.js)

## Fluxo Básico

- Instalar -> configurar -> rodar -> corrigir -> automatizar
