# 🎯 Git — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Rebase Interativo](./01%20Rebase%20Interativo): Use git rebase -i para squash, reword, edit e reorder de commits.
- [02 Rebase Upstream](./02%20Rebase%20Upstream): Mantenha sua feature branch atualizada com a main usando rebase (sem merge commits).
- [03 Git Bisect](./03%20Git%20Bisect): Use git bisect para encontrar o commit que introduziu um bug com busca binária.
- [04 Git Hooks Precommit](./04%20Git%20Hooks%20Precommit): Crie um pre-commit hook que roda o linter e impede commit se houver erros.
- [05 Git Hooks Commit Msg](./05%20Git%20Hooks%20Commit%20Msg): Crie um commit-msg hook que valida o formato Conventional Commits.
- [06 Reflog Recuperação](./06%20Reflog%20Recuperação): Use git reflog para recuperar commits ou branches deletados acidentalmente.
- [07 Filter Branch History](./07%20Filter%20Branch%20History): Use git filter-repo para remover um arquivo sensível (senha) do histórico completo.
- [08 Merge Strategies](./08%20Merge%20Strategies): Explore as estratégias de merge: ours, theirs, octopus e subtree.
- [09 Rerere](./09%20Rerere): Configure git rerere para reutilizar resoluções de conflitos que você já fez antes.
- [10 Git Grep](./10%20Git%20Grep): Use git grep para buscar padrões no código rastreado pelo Git de forma eficiente.
- [11 Monorepo Git](./11%20Monorepo%20Git): Gerencie um monorepo: use sparse-checkout, pathspec e filtros de subdiretório.
- [12 Workflow Gitflow](./12%20Workflow%20Gitflow): Implemente o GitFlow: branches main, develop, feature, release e hotfix.
- [13 Workflow Trunk Based](./13%20Workflow%20Trunk%20Based): Configure Trunk Based Development com feature flags e CI gates.
- [14 Proteger Branches](./14%20Proteger%20Branches): Configure Branch Protection Rules no GitHub: requer PRs, reviews e checks.
- [15 Codeowners](./15%20Codeowners): Configure o arquivo CODEOWNERS para revisão automática por área do código.
- [16 Release Automático](./16%20Release%20Automático): Configure o Semantic Release ou Release Please para publicação automática.
- [17 Git Archive](./17%20Git%20Archive): Use git archive para exportar um snapshot do código sem o histórico.
- [18 Signing Commits](./18%20Signing%20Commits): Configure assinatura de commits com GPG ou SSH para verificar autoria.
- [19 Split Repository](./19%20Split%20Repository): Extraia um subdiretório para um novo repositório preservando o histórico (filter-repo).
- [20 Merge Repositorios](./20%20Merge%20Repositorios): Junte dois repositórios independentes em um, preservando o histórico de ambos.
- [21 Patch Format](./21%20Patch%20Format): Gere patches com git format-patch e aplique-os com git am.
- [22 Diff Avançado](./22%20Diff%20Avançado): Use git diff --stat, --word-diff, --color-moved e compare branches remotas.
- [23 Blame Avançado](./23%20Blame%20Avançado): Use git blame -C para rastrear origem de linhas copiadas entre arquivos.
- [24 Notes Git](./24%20Notes%20Git): Use git notes para adicionar metadados a commits sem alterar o SHA.
- [25 Shallow Clone](./25%20Shallow%20Clone): Use git clone --depth=1 e --filter=blob:none para clonar repositórios grandes rapidamente.
- [26 Git Lfs](./26%20Git%20Lfs): Configure Git LFS para versionar arquivos binários grandes (imagens, vídeos, modelos ML).
- [27 Resolução Conflito Avançada](./27%20Resolução%20Conflito%20Avançada): Resolva conflitos complexos usando git mergetool, vimdiff e estratégias de 3 vias.
- [28 Git Bisect Automático](./28%20Git%20Bisect%20Automático): Automatize o git bisect com um script de teste para encontrar regressões.
- [29 Continuous Integration Git](./29%20Continuous%20Integration%20Git): Configure um pipeline CI/CD (GitHub Actions) que valida commits e PRs.
- [30 Git Internals Objetos](./30%20Git%20Internals%20Objetos): Explore os objetos internos do Git: blobs, trees, commits e tags usando git cat-file.
