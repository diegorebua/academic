# 🎯 TypeScript — Avançado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 HKT Higher Kinded](./01%20HKT%20Higher%20Kinded): Simule Higher-Kinded Types em TypeScript usando técnicas de encoding de tipos.
- [02 Type Level Arithmetic](./02%20Type%20Level%20Arithmetic): Realize aritmética no nível de tipos usando Recursive Types e Tuple manipulation.
- [03 Peano Numbers](./03%20Peano%20Numbers): Implemente os números de Peano no sistema de tipos do TypeScript (soma, comparação).
- [04 Type Safe SQL](./04%20Type%20Safe%20SQL): Crie um query builder SQL completamente tipado onde erros de coluna/tabela são detectados em compilação.
- [05 Type Safe Form](./05%20Type%20Safe%20Form): Implemente um sistema de formulários type-safe onde cada campo, validação e erro são inferidos automaticamente.
- [06 TS Plugin](./06%20TS%20Plugin): Crie um plugin do compilador TypeScript (Language Service Plugin) para adicionar regras customizadas.
- [07 Generic DI Container](./07%20Generic%20DI%20Container): Implemente um contêiner de Injeção de Dependências genérico e completamente tipado.
- [08 Dependent Types Simulado](./08%20Dependent%20Types%20Simulado): Simule Dependent Types em TypeScript (ex: Array com tamanho fixo no tipo).
- [09 Effect System](./09%20Effect%20System): Implemente um sistema de efeitos tipado (IO monad) que rastreia efeitos colaterais no tipo.
- [10 Abstract Algebra](./10%20Abstract%20Algebra): Modele estruturas da álgebra abstrata (Monoid, Functor, Applicative) em TypeScript.
- [11 Lens Optics](./11%20Lens%20Optics): Implemente Lenses e Prisms para atualização imutável e type-safe de estruturas aninhadas.
- [12 Free Monad](./12%20Free%20Monad): Implemente a Free Monad em TypeScript para separar definição de programa de interpretação.
- [13 Type Safe State Machine](./13%20Type%20Safe%20State%20Machine): Crie uma Máquina de Estados onde as transições inválidas causam erros de compilação.
- [14 Coroutine Generator Types](./14%20Coroutine%20Generator%20Types): Tipo generators e coroutines complexas usando infer e Recursive Types.
- [15 TS To JSON Schema](./15%20TS%20To%20JSON%20Schema): Crie uma ferramenta que converte tipos TypeScript em JSON Schema automaticamente.
- [16 Compiletime Assertions](./16%20Compiletime%20Assertions): Use tsd e Template Literal Types para escrever assertions de tipo em tempo de compilação.
- [17 Metaprogramming TS](./17%20Metaprogramming%20TS): Explore metaprogramação com Conditional Types e Mapped Types para criar APIs genéricas.
- [18 Pattern Matching TS](./18%20Pattern%20Matching%20TS): Implemente Pattern Matching seguro em TypeScript usando a biblioteca ts-pattern.
- [19 Nominal Typing](./19%20Nominal%20Typing): Implemente Nominal Typing robusto em uma linguagem que é estruturalmente tipada.
- [20 Arrow Types](./20%20Arrow%20Types): Use FlowType-style type annotations convertidas para TypeScript em uma codebase real.
- [21 TS ESLint Rules](./21%20TS%20ESLint%20Rules): Escreva regras ESLint customizadas para TypeScript usando @typescript-eslint/utils.
- [22 Transformations API](./22%20Transformations%20API): Crie transformações de tipos que convertem DTO ↔ Domain Model ↔ Persistence Model.
- [23 Advanced Inference](./23%20Advanced%20Inference): Domine inferência de tipos em contextos complexos: mapped types aninhados, infer em unions.
- [24 TS Interpreter](./24%20TS%20Interpreter): Implemente um interpretador de um subconjunto do TypeScript usando apenas o sistema de tipos.
- [25 Typed Event Bus](./25%20Typed%20Event%20Bus): Implemente um Event Bus totalmente tipado onde cada tópico tem um payload inferido.
- [26 DSL Type Level](./26%20DSL%20Type%20Level): Crie uma DSL (Domain Specific Language) que funciona no nível de tipos do TypeScript.
- [27 Type Safe API Client](./27%20Type%20Safe%20API%20Client): Implemente um cliente de API que infere automaticamente os tipos de resposta a partir de uma definição OpenAPI.
- [28 Monad Transformers](./28%20Monad%20Transformers): Implemente Monad Transformers para compor efeitos como Maybe + IO + Either.
- [29 TS Kernel](./29%20TS%20Kernel): Crie uma biblioteca de utilitários de tipos TypeScript publicável no npm com tipos complexos.
- [30 Full Type System](./30%20Full%20Type%20System): Implemente um sistema de tipos simples (como o Hindley-Milner) usando apenas o sistema de tipos do TypeScript.
