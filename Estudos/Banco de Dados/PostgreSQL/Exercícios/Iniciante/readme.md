# 🎯 SQL — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Select Básico](./01%20Select%20Básico): Use SELECT para buscar todas as colunas e colunas específicas de uma tabela.
- [02 Where Filtros](./02%20Where%20Filtros): Filtre registros com WHERE usando =, !=, >, <, BETWEEN, IN e LIKE.
- [03 Order By Limit](./03%20Order%20By%20Limit): Ordene resultados com ORDER BY (ASC e DESC) e limite com LIMIT/OFFSET.
- [04 Operadores Lógicos](./04%20Operadores%20Lógicos): Combine condições com AND, OR e NOT no WHERE.
- [05 Funções Agregação](./05%20Funções%20Agregação): Use COUNT, SUM, AVG, MIN e MAX para sumarizar dados.
- [06 Group By Having](./06%20Group%20By%20Having): Agrupe resultados com GROUP BY e filtre grupos com HAVING.
- [07 Alias Colunas Tabelas](./07%20Alias%20Colunas%20Tabelas): Use AS para criar aliases de colunas e tabelas para legibilidade.
- [08 Insert Dados](./08%20Insert%20Dados): Insira dados com INSERT INTO: linha única e múltiplas linhas.
- [09 Update Dados](./09%20Update%20Dados): Atualize registros com UPDATE. CUIDADO: sempre use WHERE para não atualizar tudo.
- [10 Delete Dados](./10%20Delete%20Dados): Delete registros com DELETE. Use transactions para segurança.
- [11 Criar Tabela](./11%20Criar%20Tabela): Crie tabelas com CREATE TABLE definindo tipos e constraints (NOT NULL, UNIQUE, DEFAULT).
- [12 Primary Foreign Key](./12%20Primary%20Foreign%20Key): Defina PRIMARY KEY e FOREIGN KEY. Entenda integridade referencial.
- [13 Inner Join](./13%20Inner%20Join): Una duas tabelas com INNER JOIN. Filtre apenas os registros que têm correspondência em ambas.
- [14 Left Right Join](./14%20Left%20Right%20Join): Use LEFT JOIN e RIGHT JOIN. Entenda a diferença com INNER JOIN.
- [15 Full Outer Join](./15%20Full%20Outer%20Join): Use FULL OUTER JOIN para incluir todos os registros de ambas as tabelas.
- [16 Self Join](./16%20Self%20Join): Use SELF JOIN para comparar linhas dentro da mesma tabela.
- [17 Subquery Simples](./17%20Subquery%20Simples): Use subqueries no WHERE para filtrar com base em resultados de outra query.
- [18 Distinct Uniqueness](./18%20Distinct%20Uniqueness): Use DISTINCT para eliminar duplicatas em resultados.
- [19 Null Handling](./19%20Null%20Handling): Trate valores NULL com IS NULL, IS NOT NULL e COALESCE.
- [20 Tipos Dados SQL](./20%20Tipos%20Dados%20SQL): Explore os tipos de dados: VARCHAR, TEXT, INTEGER, NUMERIC, DATE, TIMESTAMP, BOOLEAN.
- [21 Constraints Check](./21%20Constraints%20Check): Adicione constraints CHECK para validar dados na criação (ex: idade > 0).
- [22 Alter Table](./22%20Alter%20Table): Modifique tabelas com ALTER TABLE: adicionar/remover colunas, renomear.
- [23 Truncate Drop](./23%20Truncate%20Drop): Entenda a diferença entre TRUNCATE, DELETE sem WHERE e DROP TABLE.
- [24 Case When](./24%20Case%20When): Use CASE WHEN para criar lógica condicional dentro de uma query.
- [25 Concatenar Strings](./25%20Concatenar%20Strings): Use CONCAT, ||, UPPER, LOWER, TRIM, SUBSTRING e LENGTH em campos de texto.
- [26 Funções Data Hora](./26%20Funções%20Data%20Hora): Use NOW(), CURRENT_DATE, DATE_PART, AGE e EXTRACT para manipular datas.
- [27 Like Ilike](./27%20Like%20Ilike): Use LIKE e ILIKE para buscas por padrão. Entenda a performance.
- [28 Union Intersect Except](./28%20Union%20Intersect%20Except): Use UNION, INTERSECT e EXCEPT para combinar resultados de múltiplas queries.
- [29 Transações Básico](./29%20Transações%20Básico): Use BEGIN, COMMIT e ROLLBACK para agrupar operações em uma transação.
- [30 Modelo Dados Livraria](./30%20Modelo%20Dados%20Livraria): Crie o modelo de dados completo de uma livraria: Livros, Autores, Clientes, Pedidos.
