# Nível 0: Muito Fácil (Seleção Básica)

Neste nível você treinará a sintaxe fundamental do SQL para consultar dados em uma tabela.

---

### Exercício 0.1: Selecionar Todos os Campos
**Objetivo:** Escreva uma consulta para retornar todos os registros e todas as colunas da tabela `clientes`.

**Saída Esperada:**
```sql
SELECT * FROM clientes;
```

---

### Exercício 0.2: Selecionar Campos Específicos
**Objetivo:** Escreva uma consulta para retornar apenas as colunas `nome` e `email` da tabela `clientes`.

---

### Exercício 0.3: Ordenação de Resultados
**Objetivo:** Modifique a consulta anterior para retornar os clientes ordenados pelo `nome` em ordem alfabética decrescente (Z a A).
