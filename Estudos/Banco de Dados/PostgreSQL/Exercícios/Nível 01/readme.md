# Nível 1: Fácil (Filtros e Operadores)

Neste nível você praticará o uso da cláusula `WHERE` para filtrar registros baseados em condições específicas.

---

### Exercício 1.1: Filtro de Igualdade e Maior Que
**Objetivo:** Escreva uma consulta para selecionar o `nome` e o `salario` da tabela `funcionarios` onde o `cargo` seja igual a 'Desenvolvedor' e o `salario` seja maior que 5000.

---

### Exercício 1.2: Uso de IN e BETWEEN
**Objetivo:** Escreva uma consulta para selecionar todos os `produtos` cuja `categoria` seja 'Eletrônicos', 'Celulares' ou 'Informática' (use `IN`) E cujo `preco` esteja entre 1000 e 3000 (use `BETWEEN`).

---

### Exercício 1.3: Busca de Texto com LIKE
**Objetivo:** Escreva uma consulta para encontrar todos os `clientes` cujo `email` termine com `@gmail.com`.
