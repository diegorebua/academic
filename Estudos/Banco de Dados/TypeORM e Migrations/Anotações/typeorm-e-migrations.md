# Persistência e TypeORM

**O que é e qual o seu papel:** ORM que substitui o DAO manual e versiona o banco.
**Tempo Estimado:** 5 a 7 dias

## Tópicos para Estudar
- [ ] Mapeamento de Entities e Relacionamentos no código
- [ ] Active Record vs Data Mapper (uso de Repositories no NestJS)
- [ ] Transações com TypeORM
- [ ] Configuração e execução de Migrations na linha de comando

## O que é (conceito)
É o que permite os desenvolvedores integrarem com o banco de dados usando o código TS ou JS. Basicamente ele é o tradutor entre o banco de dados e o backend.
