# 🎯 AWS — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 VPC Avançada](./01%20VPC%20Avançada): Projete uma VPC multi-AZ com subnets públicas/privadas, NAT Gateway e VPC Endpoints.
- [02 Ecs Fargate API](./02%20Ecs%20Fargate%20API): Faça o deploy de uma API Node.js containerizada no ECS Fargate com ALB e auto-scaling.
- [03 RDS Alta Disponibilidade](./03%20RDS%20Alta%20Disponibilidade): Configure RDS Multi-AZ com read replicas e failover automático.
- [04 Elasticache Redis](./04%20Elasticache%20Redis): Configure ElastiCache Redis para cache de sessões e resultados de API.
- [05 SQS Lambda Processamento](./05%20SQS%20Lambda%20Processamento): Crie um pipeline assíncrono: API → SQS → Lambda processando em lote (batch).
- [06 S3 Event Trigger](./06%20S3%20Event%20Trigger): Dispare uma Lambda automaticamente quando um arquivo for enviado ao S3.
- [07 Codepipeline Cicd](./07%20Codepipeline%20Cicd): Configure um pipeline CI/CD com CodePipeline, CodeBuild e CodeDeploy para um app Node.js.
- [08 Cloudformation Básico](./08%20Cloudformation%20Básico): Provisione uma stack (EC2 + RDS + Security Groups) com um template CloudFormation.
- [09 Terraform Básico](./09%20Terraform%20Básico): Provisione a mesma infraestrutura do exercício anterior usando Terraform.
- [10 Secrets Manager](./10%20Secrets%20Manager): Armazene e recupere segredos de banco de dados com Secrets Manager com rotação automática.
- [11 WAF Shield](./11%20WAF%20Shield): Configure o WAF na frente do CloudFront para bloquear SQLi e XSS.
- [12 GuardDuty](./12%20GuardDuty): Habilite o GuardDuty e simule um ataque para ver as findings geradas.
- [13 Config Rules](./13%20Config%20Rules): Configure regras do AWS Config para auditoria de conformidade (ex: S3 sem criptografia).
- [14 XRay Tracing](./14%20XRay%20Tracing): Adicione rastreamento com X-Ray a uma função Lambda e uma API Gateway.
- [15 EventBridge Rules](./15%20EventBridge%20Rules): Configure regras no EventBridge para reagir a eventos de outros serviços AWS.
- [16 SFN Workflow Avançado](./16%20SFN%20Workflow%20Avançado): Crie um workflow Step Functions com states de erro, retry e parallel.
- [17 OpenSearch Básico](./17%20OpenSearch%20Básico): Configure o OpenSearch Service e indexe documentos para busca full-text.
- [18 MSK Kafka](./18%20MSK%20Kafka): Configure o MSK (Managed Streaming for Kafka) e crie producers/consumers.
- [19 Appsync GraphQL](./19%20Appsync%20GraphQL): Crie uma API GraphQL com AppSync conectada ao DynamoDB.
- [20 Amplify Frontend](./20%20Amplify%20Frontend): Faça o deploy de um app React no AWS Amplify com CI/CD integrado ao GitHub.
- [21 S3 Replication](./21%20S3%20Replication): Configure replicação entre buckets S3 em regiões diferentes para disaster recovery.
- [22 Global Accelerator](./22%20Global%20Accelerator): Configure o AWS Global Accelerator para reduzir latência em aplicações globais.
- [23 Lambda Layers](./23%20Lambda%20Layers): Crie Lambda Layers para compartilhar dependências entre múltiplas funções.
- [24 Lambda Powertools](./24%20Lambda%20Powertools): Use AWS Lambda Powertools para logging estruturado, tracing e métricas.
- [25 Data Pipeline Glue](./25%20Data%20Pipeline%20Glue): Crie um pipeline ETL completo com Glue: S3 → transformação → Redshift.
- [26 Athena S3](./26%20Athena%20S3): Consulte dados em S3 com Athena usando SQL e otimize o custo com Parquet.
- [27 IAM Roles Avançado](./27%20IAM%20Roles%20Avançado): Configure Cross-Account Roles, Permission Boundaries e Service Control Policies.
- [28 Network Firewall](./28%20Network%20Firewall): Configure o AWS Network Firewall para inspecionar tráfego na VPC.
- [29 Disaster Recovery](./29%20Disaster%20Recovery): Implemente uma estratégia de Pilot Light para disaster recovery multi-região.
- [30 Cost Optimization](./30%20Cost%20Optimization): Analise os custos usando Cost Explorer, Trusted Advisor e implemente 5 otimizações.
