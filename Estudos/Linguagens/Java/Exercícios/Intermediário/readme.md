# 🎯 Java — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Streams Avançados](./01%20Streams%20Avançados): Use flatMap, reduce, groupingBy, partitioningBy e Collectors customizados.
- [02 Stream Paralelo](./02%20Stream%20Paralelo): Compare Stream sequencial vs paralelo em processamento de listas grandes.
- [03 Functional Interfaces](./03%20Functional%20Interfaces): Explore Function, Predicate, Consumer, Supplier, BiFunction e crie as suas próprias.
- [04 Design Patterns Criação](./04%20Design%20Patterns%20Criação): Implemente Singleton, Factory Method, Abstract Factory, Builder e Prototype.
- [05 Design Patterns Estrutura](./05%20Design%20Patterns%20Estrutura): Implemente Adapter, Decorator, Facade, Proxy e Composite.
- [06 Design Patterns Comportamento](./06%20Design%20Patterns%20Comportamento): Implemente Strategy, Observer, Command, Iterator e Template Method.
- [07 Spring Boot CRUD](./07%20Spring%20Boot%20CRUD): Crie uma API REST CRUD com Spring Boot, Spring Data JPA e banco H2 em memória.
- [08 Spring Validation](./08%20Spring%20Validation): Adicione validação com Bean Validation (@Valid, @NotBlank, @Email) e erros customizados.
- [09 Spring Security Básico](./09%20Spring%20Security%20Básico): Configure Spring Security com autenticação via usuário/senha em memória.
- [10 Spring JWT](./10%20Spring%20JWT): Implemente autenticação JWT no Spring Boot com filtros de segurança customizados.
- [11 Spring Data Avançado](./11%20Spring%20Data%20Avançado): Use @Query, Specifications e Criteria API para queries complexas no Spring Data.
- [12 Spring Cache](./12%20Spring%20Cache): Configure cache com @Cacheable, @CacheEvict usando Redis como provider.
- [13 Spring Events](./13%20Spring%20Events): Use ApplicationEventPublisher e @EventListener para desacoplar componentes.
- [14 Spring Batch](./14%20Spring%20Batch): Processe um arquivo CSV de 1 milhão de linhas com Spring Batch.
- [15 Spring Scheduler](./15%20Spring%20Scheduler): Use @Scheduled para criar tarefas agendadas no Spring Boot.
- [16 Threads Executors](./16%20Threads%20Executors): Use ExecutorService, ThreadPoolExecutor, Callable e Future para paralelismo.
- [17 Completable Future](./17%20Completable%20Future): Use CompletableFuture para encadear operações assíncronas sem bloquear.
- [18 Virtual Threads](./18%20Virtual%20Threads): Use Virtual Threads (Java 21 Project Loom) para alta concorrência com código simples.
- [19 Record Sealed Java](./19%20Record%20Sealed%20Java): Use Records e Sealed Classes para modelar dados algébricos de forma segura.
- [20 Pattern Matching Java](./20%20Pattern%20Matching%20Java): Use Pattern Matching com instanceof e switch expressions (Java 17+).
- [21 Httpclient Java](./21%20Httpclient%20Java): Use o java.net.http.HttpClient (Java 11+) para fazer requisições HTTP assíncronas.
- [22 Jdbc Template](./22%20Jdbc%20Template): Use JdbcTemplate do Spring para executar queries SQL de forma segura (sem ORM).
- [23 Mapstruct Mapper](./23%20Mapstruct%20Mapper): Use MapStruct para gerar mappers entre DTOs e entidades de domínio.
- [24 Lombok Java](./24%20Lombok%20Java): Configure Lombok: @Data, @Builder, @RequiredArgsConstructor e seus impactos.
- [25 Mock JUnit](./25%20Mock%20JUnit): Escreva testes com JUnit 5 e Mockito: @Mock, @InjectMocks, @Captor.
- [26 Test Containers](./26%20Test%20Containers): Use Testcontainers para testes de integração com PostgreSQL, Redis e Kafka em containers.
- [27 JaCoCo Cobertura](./27%20JaCoCo%20Cobertura): Configure JaCoCo para medir cobertura de testes e estabeleça limites mínimos.
- [28 Actuator Monitoramento](./28%20Actuator%20Monitoramento): Configure Spring Boot Actuator com Micrometer, Prometheus e Grafana.
- [29 OpenAPI Swagger Java](./29%20OpenAPI%20Swagger%20Java): Documente a API com SpringDoc OpenAPI e customize o Swagger UI.
- [30 Flyway Migrations](./30%20Flyway%20Migrations): Use Flyway para gerenciar migrações de banco de dados de forma versionada.
