# 🎯 Go — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 API REST Stdlib](./01%20API%20REST%20Stdlib): Crie uma API REST CRUD para 'Produtos' usando apenas net/http com ServeMux.
- [02 API REST Chi](./02%20API%20REST%20Chi): Refatore a API usando o roteador Chi com middlewares de log, CORS e autenticação.
- [03 Banco PostgreSQL](./03%20Banco%20PostgreSQL): Conecte ao PostgreSQL usando pgx e implemente operações CRUD com prepared statements.
- [04 Migrations Goose](./04%20Migrations%20Goose): Use goose ou migrate para gerenciar migrações de banco de dados.
- [05 Goroutines Worker Pool](./05%20Goroutines%20Worker%20Pool): Implemente um Worker Pool com número fixo de goroutines processando tarefas de um channel.
- [06 Select Statement](./06%20Select%20Statement): Use select para multiplexar channels: timeout, cancelamento e prioridade.
- [07 Context Cancelamento](./07%20Context%20Cancelamento): Use context.Context para cancelar goroutines e propagar deadlines em requisições HTTP.
- [08 Interface Avançada](./08%20Interface%20Avançada): Explore duck typing com interfaces: io.Reader, io.Writer, fmt.Stringer.
- [09 Generics Go](./09%20Generics%20Go): Use generics (Go 1.18+) para criar funções e estruturas de dados genéricas: Map, Filter, Reduce.
- [10 Testes Unitários Go](./10%20Testes%20Unitários%20Go): Escreva testes com testing, subtests (t.Run), testes de tabela e mocks com testify.
- [11 Benchmarks Go](./11%20Benchmarks%20Go): Escreva benchmarks para comparar algoritmos (busca, ordenação) e otimize com os resultados.
- [12 Middleware Cadeia](./12%20Middleware%20Cadeia): Crie uma cadeia de middlewares HTTP reutilizáveis: log, auth, rate limit, CORS.
- [13 JWT Auth](./13%20JWT%20Auth): Implemente autenticação JWT: geração, validação e middleware de proteção de rotas.
- [14 gRPC Go](./14%20gRPC%20Go): Crie um servidor e cliente gRPC com Protobuf para gerenciar usuários.
- [15 Streaming gRPC](./15%20Streaming%20gRPC): Implemente gRPC com Server Streaming para transmitir resultados de busca progressivamente.
- [16 RabbitMQ Go](./16%20RabbitMQ%20Go): Publique e consuma mensagens no RabbitMQ usando amqp091-go.
- [17 Redis Go](./17%20Redis%20Go): Use Redis com go-redis para cache, pub/sub e listas de tarefas.
- [18 Embed Arquivos](./18%20Embed%20Arquivos): Use go:embed para incluir arquivos estáticos (HTML, SQL, configs) no binário.
- [19 Reflection Go](./19%20Reflection%20Go): Explore o pacote reflect para criar funções genéricas antes dos generics e validadores.
- [20 Plugin Go](./20%20Plugin%20Go): Compile e carregue plugins Go dinâmicos em runtime usando o pacote plugin.
- [21 Profiling Pprof](./21%20Profiling%20Pprof): Profile a aplicação com pprof: CPU, memória e goroutine leak detection.
- [22 CLI Cobra](./22%20CLI%20Cobra): Crie uma CLI robusta com sub-comandos usando Cobra e Viper.
- [23 Websocket Go](./23%20Websocket%20Go): Implemente um servidor WebSocket com gorilla/websocket para um chat em tempo real.
- [24 TLS HTTPS](./24%20TLS%20HTTPS): Configure HTTPS com TLS usando certificados auto-assinados no servidor Go.
- [25 Graceful Shutdown Go](./25%20Graceful%20Shutdown%20Go): Implemente graceful shutdown aguardando todas as requisições finalizarem.
- [26 Rate Limiting Go](./26%20Rate%20Limiting%20Go): Implemente rate limiting com golang.org/x/time/rate (Token Bucket).
- [27 Dependency Injection Go](./27%20Dependency%20Injection%20Go): Use wire ou fx para gerenciar injeção de dependências em uma aplicação maior.
- [28 Mock Interfaces Go](./28%20Mock%20Interfaces%20Go): Use mockery para gerar mocks de interfaces e escreva testes de unidade isolados.
- [29 Pipeline Funcional Go](./29%20Pipeline%20Funcional%20Go): Implemente pipeline de processamento de dados usando goroutines e channels encadeados.
- [30 XML YAML Go](./30%20XML%20YAML%20Go): Serialize e desserialize dados em XML e YAML. Compare com JSON.
