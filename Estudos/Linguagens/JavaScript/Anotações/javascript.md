# JavaScript

**O que é e qual o seu papel:** Linguagem base do Node.js e do browser. Entender os métodos nativos de array e string evita bugs sutis no dia a dia.
**Tempo Estimado:** 7 a 14 dias

## Tópicos para Estudar
- [ ] Tipos primitivos e referência (string, number, boolean, array, object)
- [ ] Métodos de array: `map`, `filter`, `reduce`, `find`, `some`, `every`, `includes`
- [ ] Métodos de string: `includes`, `startsWith`, `endsWith`, `split`, `replace`
- [ ] Diferença entre `includes` (igualdade exata) e `some` + `startsWith` (busca flexível)
- [ ] `process.argv` — como o Node.js recebe argumentos da linha de comando
- [ ] Funções arrow vs function declaration
- [ ] Destructuring de objetos e arrays
- [ ] Promises, async/await e tratamento de erros
- [ ] Closures e escopo de variáveis
