# 🎯 JavaScript — Avançado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 SPA Roteador](./01%20SPA%20Roteador): Crie um roteador de Single Page Application do zero usando a History API, com rotas dinâmicas e guards.
- [02 Reatividade Vue Like](./02%20Reatividade%20Vue%20Like): Implemente um sistema de reatividade simples similar ao Vue 2, usando Object.defineProperty e watchers.
- [03 State Machine](./03%20State%20Machine): Implemente uma Máquina de Estados Finitos (FSM) genérica e use-a para modelar um carrinho de compras.
- [04 Interpreter](./04%20Interpreter): Crie um interpretador de uma linguagem de script simples (variáveis, ifs, loops) usando um lexer e parser.
- [05 Promise Implementation](./05%20Promise%20Implementation): Implemente sua própria Promise do zero, compatível com a especificação Promises/A+.
- [06 Rx Observable](./06%20Rx%20Observable): Implemente um mini RxJS com Observable, Subject, e os operadores map, filter, mergeMap.
- [07 Module Bundler](./07%20Module%20Bundler): Crie um module bundler simplificado (inspirado no Webpack) que resolve imports/requires e gera um bundle.
- [08 Template Engine](./08%20Template%20Engine): Crie um motor de templates com suporte a variáveis {{var}}, loops {{#each}} e condicionais {{#if}}.
- [09 Memoização Avançada](./09%20Memoização%20Avançada): Implemente memoização com suporte a argumentos complexos (objetos e arrays), usando serialização e WeakMap.
- [10 Proxy Interceptor](./10%20Proxy%20Interceptor): Use a API Proxy do JavaScript para criar um framework de validação de objetos declarativo.
- [11 Framework Reativo](./11%20Framework%20Reativo): Crie um micro-framework de UI reativo com componentes, props, estado e re-renderização eficiente.
- [12 Compilador Expressões](./12%20Compilador%20Expressões): Implemente um compilador de expressões matemáticas que converte infix para postfix e depois avalia.
- [13 Scheduler Tarefas](./13%20Scheduler%20Tarefas): Crie um scheduler de tarefas assíncronas com prioridades, filas e suporte a cancelamento.
- [14 Transpiler Básico](./14%20Transpiler%20Básico): Crie um transpiler que converte arrow functions e template literals para ES5.
- [15 Type System](./15%20Type%20System): Implemente um sistema de tipos em runtime para JavaScript, validando tipos primitivos, objetos e genéricos.
- [16 Event Sourcing](./16%20Event%20Sourcing): Implemente um sistema simples de Event Sourcing onde o estado é derivado de uma sequência de eventos imutáveis.
- [17 Cqrs Pattern](./17%20Cqrs%20Pattern): Implemente o padrão CQRS (Command Query Responsibility Segregation) em uma aplicação de gerenciamento de estoque.
- [18 VM JavaScript](./18%20VM%20JavaScript): Crie uma máquina virtual baseada em bytecode que executa um subconjunto de operações JavaScript.
- [19 Circuit Breaker](./19%20Circuit%20Breaker): Implemente o padrão Circuit Breaker para chamadas de API, com estados Closed, Open e Half-Open.
- [20 Dependency Injection](./20%20Dependency%20Injection): Crie um contêiner de Injeção de Dependências simples que resolve dependências automaticamente.
- [21 LRU Cache](./21%20LRU%20Cache): Implemente um cache LRU (Least Recently Used) usando um Map e uma lista duplamente encadeada.
- [22 Diff Algorithm](./22%20Diff%20Algorithm): Implemente o algoritmo de diff de strings/arrays (similar ao que o Git usa para mostrar diferenças).
- [23 Csp Interpreter](./23%20Csp%20Interpreter): Crie um interpretador de Communicating Sequential Processes (CSP) com channels e goroutines simuladas.
- [24 JIT Compiler](./24%20JIT%20Compiler): Simule um compilador JIT simples que otimiza funções puras chamadas repetidamente.
- [25 Reactive Db](./25%20Reactive%20Db): Crie um banco de dados reativo em memória que notifica assinantes quando os dados mudam (similar ao Firebase Realtime DB).
- [26 Ast Transformer](./26%20Ast%20Transformer): Crie um transformador de AST (Abstract Syntax Tree) que refatora automaticamente código JavaScript.
- [27 Concorrência Promises](./27%20Concorrência%20Promises): Implemente Promise.all, Promise.race, Promise.any e Promise.allSettled do zero.
- [28 Signal System](./28%20Signal%20System): Implemente um sistema de Signals (similar ao SolidJS) com computeds e effects automáticos.
- [29 WASM Integration](./29%20WASM%20Integration): Crie um módulo WebAssembly em C/Rust e integre-o com JavaScript para um cálculo intensivo.
- [30 Micro Frontend](./30%20Micro%20Frontend): Implemente a arquitetura de Micro Frontends com module federation manual e comunicação entre apps.
