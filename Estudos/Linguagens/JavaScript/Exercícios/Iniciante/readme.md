# 🎯 JavaScript — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Hello World](./01%20Hello%20World): Escreva um script que imprime 'Olá, Mundo!' no console e depois peça o nome do usuário (via prompt ou readline) e cumprimente-o.
- [02 Calculadora](./02%20Calculadora): Crie uma calculadora de operações básicas (soma, subtração, multiplicação, divisão) que leia dois números e o operador.
- [03 Fizzbuzz](./03%20Fizzbuzz): Implemente o clássico FizzBuzz: para múltiplos de 3 imprima 'Fizz', de 5 'Buzz' e de ambos 'FizzBuzz'.
- [04 Palíndromo](./04%20Palíndromo): Crie uma função que verifica se uma string é um palíndromo (ignora espaços e maiúsculas).
- [05 Par Ímpar](./05%20Par%20Ímpar): Verifique se um número é par ou ímpar. Itere de 1 a 100 e imprima todos os pares.
- [06 Fibonacci](./06%20Fibonacci): Gere os N primeiros números da sequência de Fibonacci.
- [07 Fatorial](./07%20Fatorial): Calcule o fatorial de um número usando recursão e iteração. Compare os resultados.
- [08 Inverter String](./08%20Inverter%20String): Inverta uma string sem usar .reverse() no array internamente (resolva manualmente).
- [09 Maior Número](./09%20Maior%20Número): Dada uma lista de números, encontre o maior e o menor sem usar Math.max/min.
- [10 Média Notas](./10%20Média%20Notas): Leia um array de notas de alunos, calcule a média e diga se o aluno foi aprovado (>=7).
- [11 Remover Duplicatas](./11%20Remover%20Duplicatas): Remova os elementos duplicados de um array de diversas formas (Set, filter, reduce).
- [12 Contar Vogais](./12%20Contar%20Vogais): Conte quantas vogais existem em uma string fornecida pelo usuário.
- [13 Validar Email](./13%20Validar%20Email): Crie uma função que valida se uma string é um e-mail válido usando Regex.
- [14 Converter Temperatura](./14%20Converter%20Temperatura): Converta temperaturas entre Celsius, Fahrenheit e Kelvin.
- [15 Tabuada](./15%20Tabuada): Imprima a tabuada de um número de 1 a 10 fornecido pelo usuário.
- [16 Anagrama](./16%20Anagrama): Verifique se duas palavras são anagramas uma da outra.
- [17 Bubble Sort](./17%20Bubble%20Sort): Implemente o algoritmo Bubble Sort manualmente para ordenar um array.
- [18 Contar Palavras](./18%20Contar%20Palavras): Conte quantas vezes cada palavra aparece em um texto e exiba as 5 mais frequentes.
- [19 Número Primo](./19%20Número%20Primo): Crie uma função que verifica se um número é primo. Liste todos os primos até N.
- [20 Jogo Adivinha](./20%20Jogo%20Adivinha): Crie o jogo de adivinhar o número: o computador escolhe um número aleatório e o usuário tenta adivinhar em até 7 tentativas.
- [21 Pilha Fila](./21%20Pilha%20Fila): Implemente as estruturas de dados Pilha (Stack) e Fila (Queue) usando arrays e objetos.
- [22 Matriz Transposta](./22%20Matriz%20Transposta): Dada uma matriz N×M, calcule e exiba a sua transposta.
- [23 Conversor Moeda](./23%20Conversor%20Moeda): Crie um conversor de moeda simples (BRL → USD → EUR) com taxas fixas definidas no código.
- [24 MDC MMC](./24%20MDC%20MMC): Calcule o MDC (Máximo Divisor Comum) e o MMC (Mínimo Múltiplo Comum) de dois números.
- [25 Validar Cpf](./25%20Validar%20Cpf): Implemente a validação de CPF usando o algoritmo oficial dos dígitos verificadores.
- [26 Roman Para Inteiro](./26%20Roman%20Para%20Inteiro): Converta números romanos para inteiros e vice-versa.
- [27 Gerador Senha](./27%20Gerador%20Senha): Crie um gerador de senhas aleatórias com parâmetros: tamanho, incluir maiúsculas, números e símbolos.
- [28 Compressão RLE](./28%20Compressão%20RLE): Implemente a compressão Run-Length Encoding (RLE) para uma string (ex: 'AAABBC' → '3A2B1C').
- [29 Busca Binária](./29%20Busca%20Binária): Implemente a busca binária em um array ordenado e compare com busca linear.
- [30 Linked List](./30%20Linked%20List): Implemente uma lista encadeada simples com operações de inserir no início, fim, remover e buscar.
