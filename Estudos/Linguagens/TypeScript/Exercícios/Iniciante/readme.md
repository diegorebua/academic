# 🎯 TypeScript — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Tipos Básicos](./01%20Tipos%20Básicos): Declare variáveis com tipos primitivos (string, number, boolean, null, undefined) e entenda as diferenças.
- [02 Interfaces Básicas](./02%20Interfaces%20Básicas): Crie interfaces para modelar Livro, Autor e Editora. Instancie objetos e valide os tipos.
- [03 Type Alias](./03%20Type%20Alias): Use type alias para criar tipos customizados. Compare com interfaces e entenda quando usar cada um.
- [04 Arrays Tuplas](./04%20Arrays%20Tuplas): Declare arrays tipados e tuplas. Crie uma função que retorna uma tupla [erro, resultado].
- [05 Enums](./05%20Enums): Crie Enums para representar os Status de um Pedido (PENDENTE, PROCESSANDO, ENVIADO, ENTREGUE, CANCELADO).
- [06 Funções Tipadas](./06%20Funções%20Tipadas): Tipar parâmetros, retornos e funções de callback. Implemente sobrecarga de funções.
- [07 Union Intersection](./07%20Union%20Intersection): Use Union Types (A | B) e Intersection Types (A & B) para representar dados flexíveis.
- [08 Optional Chaining](./08%20Optional%20Chaining): Demonstre o uso de optional chaining (?.) e nullish coalescing (??) com TypeScript.
- [09 Type Assertions](./09%20Type%20Assertions): Use as e satisfies para realizar asserções de tipo de forma segura.
- [10 Literal Types](./10%20Literal%20Types): Crie Literal Types para representar direções ('norte' | 'sul' | 'leste' | 'oeste').
- [11 Readonly Const](./11%20Readonly%20Const): Aplique readonly em interfaces e const assertions em objetos para criar dados imutáveis.
- [12 Funções Genéricas Simples](./12%20Funções%20Genéricas%20Simples): Crie funções genéricas simples: identidade, primeiro elemento de array, last.
- [13 Narrowing](./13%20Narrowing): Pratique type narrowing com typeof, instanceof, in e discriminated unions.
- [14 Classe Básica](./14%20Classe%20Básica): Crie uma classe Pessoa com propriedades tipadas, construtor, getters/setters e métodos.
- [15 Herança TS](./15%20Herança%20TS): Implemente herança entre classes Animal → Cachorro, Gato com métodos abstratos.
- [16 Interfaces Classes](./16%20Interfaces%20Classes): Implemente interfaces em classes concretas. Crie uma interface Forma com área() e perímetro().
- [17 Modificadores Acesso](./17%20Modificadores%20Acesso): Demonstre public, private, protected e readonly em uma classe BankAccount.
- [18 Decorators Simples](./18%20Decorators%20Simples): Crie um decorator simples de log que registra chamadas de método com timestamp.
- [19 Tipos Utilitários Básicos](./19%20Tipos%20Utilitários%20Básicos): Pratique Partial<T>, Required<T>, Readonly<T> e Record<K, V> em exemplos reais.
- [20 Refatorar JS Para TS](./20%20Refatorar%20JS%20Para%20TS): Pegue um arquivo JavaScript existente e refatore-o completamente para TypeScript tipado.
- [21 Namespace](./21%20Namespace): Organize código em Namespaces TypeScript. Entenda as diferenças com módulos ES6.
- [22 Generics Constraints](./22%20Generics%20Constraints): Use constraints em genéricos: <T extends object>, <T extends keyof U>.
- [23 Mapped Types Básicos](./23%20Mapped%20Types%20Básicos): Crie Mapped Types simples: MyReadonly<T>, MyPartial<T>, MyRequired<T>.
- [24 Template Literal Types](./24%20Template%20Literal%20Types): Use Template Literal Types para criar tipos de rotas de API: '/users/${string}'.
- [25 Conditional Types Básicos](./25%20Conditional%20Types%20Básicos): Escreva Conditional Types simples: IsString<T>, IsArray<T>.
- [26 Index Signatures](./26%20Index%20Signatures): Use Index Signatures para representar dicionários e mapeamentos dinâmicos.
- [27 Função Overload](./27%20Função%20Overload): Implemente uma função parse que aceita string ou Uint8Array com sobrecarga de tipo.
- [28 Discriminated Union](./28%20Discriminated%20Union): Modele os estados de uma requisição HTTP usando Discriminated Unions.
- [29 Never Type](./29%20Never%20Type): Demonstre o uso do tipo never em exhaustive checks e funções que nunca retornam.
- [30 TSConfig Explorar](./30%20TSConfig%20Explorar): Explore as opções do tsconfig.json: strict, esModuleInterop, paths, baseUrl e incremental.
