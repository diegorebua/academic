# 🎯 TypeScript — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Generic Repository](./01%20Generic%20Repository): Crie um repositório genérico Repository<T> com métodos findById, findAll, save, delete.
- [02 Utility Types Avançados](./02%20Utility%20Types%20Avançados): Pratique Pick, Omit, Exclude, Extract, NonNullable, ReturnType e Parameters.
- [03 Infer Keyword](./03%20Infer%20Keyword): Use infer dentro de Conditional Types para extrair tipos de Promises, arrays e funções.
- [04 Decorators Avançados](./04%20Decorators%20Avançados): Implemente decorators de classe, método, propriedade e parâmetro para um framework de validação.
- [05 Mixins](./05%20Mixins): Implemente o padrão de Mixins para compor comportamentos reutilizáveis em classes.
- [06 Builder Pattern TS](./06%20Builder%20Pattern%20TS): Implemente o padrão Builder com TypeScript para construir objetos complexos de forma fluente e tipada.
- [07 Zod Validação](./07%20Zod%20Validação): Use a biblioteca Zod para validar e inferir tipos de dados de uma API externa.
- [08 API Tipada](./08%20API%20Tipada): Crie uma camada de API totalmente tipada usando fetch genérico e tipos de resposta da API.
- [09 React TypeScript](./09%20React%20TypeScript): Configure um projeto React + TypeScript. Tipe props, state, eventos e refs.
- [10 Redux TypeScript](./10%20Redux%20TypeScript): Configure Redux Toolkit com TypeScript, tipando actions, reducers e seletores.
- [11 Generic Event Emitter](./11%20Generic%20Event%20Emitter): Crie um EventEmitter genérico e tipado onde os nomes dos eventos e os payloads são inferidos.
- [12 Type Safe Router](./12%20Type%20Safe%20Router): Implemente um roteador type-safe onde as rotas, parâmetros e queries são totalmente tipados.
- [13 Factory Pattern TS](./13%20Factory%20Pattern%20TS): Implemente o padrão Factory com TypeScript para criar instâncias de objetos de forma tipada.
- [14 Strategy Pattern TS](./14%20Strategy%20Pattern%20TS): Implemente o padrão Strategy para um sistema de pagamento (Cartão, PIX, Boleto) com TypeScript.
- [15 Result Type](./15%20Result%20Type): Crie um tipo Result<T, E> (similar ao Rust) e use-o para tratamento de erros sem exceções.
- [16 Either Monad](./16%20Either%20Monad): Implemente a mônada Either para encadear operações que podem falhar de forma tipada.
- [17 Branded Types](./17%20Branded%20Types): Use Branded Types para tornar tipos primitivos incompatíveis (UserId não aceita ProductId).
- [18 Opaque Types](./18%20Opaque%20Types): Implemente Opaque Types para encapsular lógica de negócio e evitar mistura de IDs.
- [19 Phantom Types](./19%20Phantom%20Types): Use Phantom Types para adicionar informações de tipo em tempo de compilação sem custo em runtime.
- [20 TypeScript Compiler API](./20%20TypeScript%20Compiler%20API): Explore a API do compilador TypeScript para ler um arquivo .ts e extrair informações de tipos.
- [21 Template Literal Avançado](./21%20Template%20Literal%20Avançado): Combine Template Literal Types com Mapped Types para criar tipos de eventos (onClick → 'click').
- [22 Recursive Types](./22%20Recursive%20Types): Crie Recursive Types para representar estruturas de árvore e JSON aninhado.
- [23 Variadic Tuple Types](./23%20Variadic%20Tuple%20Types): Use Variadic Tuple Types para implementar funções pipe e compose completamente tipadas.
- [24 Satisfies Operator](./24%20Satisfies%20Operator): Demonstre casos de uso do operador satisfies para validar configurações e literais.
- [25 Using Declaration](./25%20Using%20Declaration): Use a declaração using (TC39 proposal) com Symbol.dispose para gerenciamento de recursos.
- [26 TS Monorepo](./26%20TS%20Monorepo): Configure um monorepo com TypeScript usando Project References e workspaces.
- [27 Strict Mode Erros](./27%20Strict%20Mode%20Erros): Ative o modo strict completo e corrija todos os erros em um código legado problemático.
- [28 Test Tipagem](./28%20Test%20Tipagem): Use a biblioteca tsd ou expect-type para escrever testes de tipagem de TypeScript.
- [29 ORM Tipado](./29%20ORM%20Tipado): Use Prisma ou TypeORM com TypeScript para criar, ler, atualizar e deletar registros tipados.
- [30 Dts Gerador](./30%20Dts%20Gerador): Gere arquivos .d.ts para uma biblioteca JavaScript existente sem TypeScript.
