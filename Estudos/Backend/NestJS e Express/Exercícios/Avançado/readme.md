# 🎯 NodeJS — Avançado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Clean Architecture](./01%20Clean%20Architecture): Refatore a API para Clean Architecture com camadas separadas: Domain, Application, Infrastructure.
- [02 Cqrs Event Sourcing](./02%20Cqrs%20Event%20Sourcing): Implemente CQRS com Event Sourcing: estados derivados de eventos imutáveis, com replay.
- [03 Microsserviços Comunicação](./03%20Microsserviços%20Comunicação): Crie dois microserviços que se comunicam via RabbitMQ (Pub/Sub e Work Queues).
- [04 Kafka Streaming](./04%20Kafka%20Streaming): Configure Apache Kafka e crie um producer/consumer para processar eventos em alta escala.
- [05 Ddd Dominio](./05%20Ddd%20Dominio): Modele um domínio de e-commerce usando DDD: Aggregates, Entities, Value Objects, Repositories.
- [06 Performance Profiling](./06%20Performance%20Profiling): Profile e otimize uma API lenta usando clinic.js, flame graphs e v8-profiler.
- [07 Memory Leaks](./07%20Memory%20Leaks): Encontre e corrija memory leaks em uma aplicação Node.js usando heapdump e Chrome DevTools.
- [08 Worker Threads](./08%20Worker%20Threads): Use worker_threads para processamento paralelo de CPU-intensive tasks.
- [09 Custom Runtime](./09%20Custom%20Runtime): Crie um runtime customizado usando vm.Script ou vm.Module para execução segura de código.
- [10 Plugin System](./10%20Plugin%20System): Implemente um sistema de plugins dinâmicos que carrega módulos em runtime.
- [11 Distributed Tracing](./11%20Distributed%20Tracing): Adicione distributed tracing com OpenTelemetry e Jaeger para rastrear requisições entre serviços.
- [12 Feature Flags](./12%20Feature%20Flags): Implemente um sistema de feature flags com rollout gradual e targeting de usuários.
- [13 API Mesh](./13%20API%20Mesh): Configure uma camada de API Mesh com Apollo Federation juntando múltiplos subgraphs GraphQL.
- [14 Saga Pattern](./14%20Saga%20Pattern): Implemente o padrão Saga (coreografia e orquestração) para transações distribuídas.
- [15 Outbox Pattern](./15%20Outbox%20Pattern): Implemente o padrão Outbox para garantir entrega de eventos sem perda em falhas parciais.
- [16 Schema Registry](./16%20Schema%20Registry): Configure um Schema Registry para validar mensagens Kafka com Avro schemas.
- [17 Blue Green Deployment](./17%20Blue%20Green%20Deployment): Implemente Blue-Green Deployment com zero downtime na troca de versões.
- [18 Chaos Engineering](./18%20Chaos%20Engineering): Crie testes de Chaos Engineering simulando falhas de rede, latência e crashes.
- [19 Observabilidade Stack](./19%20Observabilidade%20Stack): Configure uma stack completa de observabilidade: Prometheus + Grafana + Loki.
- [20 Node Custom GC](./20%20Node%20Custom%20GC): Experimente e configure o Garbage Collector do V8 para otimizar o consumo de memória.
- [21 Native Addon](./21%20Native%20Addon): Crie um Native Addon em C++ usando node-addon-api para expor uma funcionalidade de sistema.
- [22 Snapshot Testing](./22%20Snapshot%20Testing): Implemente snapshot testing da API e do banco de dados para detectar regressões.
- [23 Contract Testing](./23%20Contract%20Testing): Implemente Consumer-Driven Contract Testing com Pact entre serviços.
- [24 API Rate Throttle Avançado](./24%20API%20Rate%20Throttle%20Avançado): Implemente rate limiting distribuído usando Redis com o algoritmo Token Bucket.
- [25 Multi Region Deploy](./25%20Multi%20Region%20Deploy): Projete e documente um deploy multi-região com failover automático e latência mínima.
- [26 Zero Trust Security](./26%20Zero%20Trust%20Security): Implemente uma arquitetura Zero Trust com autenticação mútua (mTLS) entre serviços.
- [27 Serverless Local](./27%20Serverless%20Local): Emule o ambiente de Lambda com serverless-offline e escreva funções serverless em Node.js.
- [28 WASM Node](./28%20WASM%20Node): Integre um módulo WebAssembly de alta performance em uma API Node.js.
- [29 Event Loop Internals](./29%20Event%20Loop%20Internals): Crie exemplos que demonstram cada fase do Event Loop: timers, I/O, idle, check, close.
- [30 Node Stream Backpressure](./30%20Node%20Stream%20Backpressure): Implemente um pipeline de Streams com controle de backpressure para não estourar memória.
