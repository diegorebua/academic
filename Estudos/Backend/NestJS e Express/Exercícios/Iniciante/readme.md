# 🎯 NodeJS — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Hello Server](./01%20Hello%20Server): Crie um servidor HTTP nativo que responde 'Olá, Mundo!' em diferentes rotas.
- [02 Leitura Arquivo](./02%20Leitura%20Arquivo): Leia um arquivo .txt com fs.readFile e escreva o resultado processado em outro arquivo.
- [03 CLI Argumentos](./03%20CLI%20Argumentos): Crie um script CLI que lê argumentos do process.argv e executa ações diferentes.
- [04 Módulos Customizados](./04%20Módulos%20Customizados): Crie módulos separados e importe-os usando require e ES Modules (import/export).
- [05 Path Os](./05%20Path%20Os): Use os módulos path e os para exibir informações do sistema e manipular caminhos.
- [06 Env Dotenv](./06%20Env%20Dotenv): Configure variáveis de ambiente com .env usando dotenv. Nunca exponha segredos no código.
- [07 Readline Interativo](./07%20Readline%20Interativo): Crie um programa interativo usando readline que simula um menu de opções.
- [08 Events Emitter](./08%20Events%20Emitter): Use o EventEmitter do Node.js para criar um sistema de eventos customizado.
- [09 Timers Node](./09%20Timers%20Node): Demonstre setTimeout, setInterval, setImmediate e process.nextTick com suas diferenças.
- [10 Buffers Streams Básico](./10%20Buffers%20Streams%20Básico): Leia um arquivo usando Streams (fs.createReadStream) e processe linha por linha.
- [11 HTTP Request Sem Lib](./11%20HTTP%20Request%20Sem%20Lib): Faça uma requisição HTTP GET para uma API pública usando apenas o módulo http/https nativo.
- [12 Child Process](./12%20Child%20Process): Execute um comando do sistema (ex: ls, pwd) usando child_process.exec e capture a saída.
- [13 Crypto Hash](./13%20Crypto%20Hash): Use o módulo crypto para gerar hashes SHA-256 de strings e comparar de forma segura.
- [14 Zlib Compressão](./14%20Zlib%20Compressão): Comprima e descomprima um arquivo usando zlib (gzip) via Streams.
- [15 URL Parse](./15%20URL%20Parse): Parse e manipule URLs usando o módulo url nativo. Extraia pathname, query params e hostname.
- [16 JSON Manipulação](./16%20JSON%20Manipulação): Leia um arquivo JSON grande, filtre e transforme os dados, e escreva um novo arquivo JSON.
- [17 Glob Padrões](./17%20Glob%20Padrões): Use glob patterns para listar arquivos recursivamente em um diretório.
- [18 Watch Arquivos](./18%20Watch%20Arquivos): Use fs.watch para monitorar mudanças em um arquivo e reagir automaticamente.
- [19 Calculator CLI](./19%20Calculator%20CLI): Crie uma calculadora de linha de comando que funciona como uma calculadora de pilha (RPN).
- [20 Concurrent Downloads](./20%20Concurrent%20Downloads): Baixe múltiplos arquivos simultaneamente usando Promise.all e streams.
- [21 Server Estático](./21%20Server%20Estático): Crie um servidor de arquivos estáticos que serve HTML, CSS e JS com os Content-Types corretos.
- [22 Logger Personalizado](./22%20Logger%20Personalizado): Crie um logger com níveis (DEBUG, INFO, WARN, ERROR) que escreve em arquivo e console.
- [23 Config Manager](./23%20Config%20Manager): Crie um gerenciador de configurações que lê de arquivo JSON, variáveis de ambiente e argumentos CLI.
- [24 Task Runner](./24%20Task%20Runner): Crie um task runner simples que executa scripts definidos em um arquivo de configuração YAML/JSON.
- [25 Ping Hosts](./25%20Ping%20Hosts): Crie um script que pinga uma lista de hosts em paralelo e reporta quais estão online.
- [26 Gerador Relatório](./26%20Gerador%20Relatório): Leia um CSV de vendas e gere um relatório em TXT com totais por categoria.
- [27 CLI Todo](./27%20CLI%20Todo): Crie uma CLI de To-Do List que persiste dados em um arquivo JSON local.
- [28 Validador JSON](./28%20Validador%20JSON): Crie um validador de arquivos JSON que verifica estrutura contra um schema definido.
- [29 Conversor Encoding](./29%20Conversor%20Encoding): Converta arquivos entre encodings (UTF-8, Latin-1) usando Buffer e streams.
- [30 TCP Socket](./30%20TCP%20Socket): Crie um servidor e cliente TCP simples usando o módulo net do Node.js.
