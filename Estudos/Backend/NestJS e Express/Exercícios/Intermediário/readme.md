# 🎯 NodeJS — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 API REST Express](./01%20API%20REST%20Express): Crie uma API REST CRUD completa para 'Produtos' usando Express com dados em memória.
- [02 Middlewares Customizados](./02%20Middlewares%20Customizados): Implemente middlewares de autenticação JWT, log de requisições e tratamento de erros global.
- [03 Banco De Dados SQLite](./03%20Banco%20De%20Dados%20SQLite): Conecte a API ao SQLite usando better-sqlite3. Implemente migrações e seeds.
- [04 Upload Arquivos](./04%20Upload%20Arquivos): Implemente upload de arquivos com Multer: valide tipo, tamanho e salve com nome único.
- [05 Rate Limiting](./05%20Rate%20Limiting): Adicione rate limiting à API com express-rate-limit e estratégias por IP e por usuário.
- [06 Cache Redis](./06%20Cache%20Redis): Implemente cache de respostas de API usando Redis com invalidação por tempo e por evento.
- [07 Filas Bullmq](./07%20Filas%20Bullmq): Use BullMQ para processar tarefas em background: envio de e-mail, geração de relatório.
- [08 Websocket Socket IO](./08%20Websocket%20Socket%20IO): Crie um chat em tempo real com salas usando Socket.io, com histórico de mensagens.
- [09 Autenticação Completa](./09%20Autenticação%20Completa): Implemente autenticação completa: registro, login, refresh token, logout e rota protegida.
- [10 Testes Unitários Jest](./10%20Testes%20Unitários%20Jest): Escreva testes unitários com Jest para as funções de negócio da API (mocking de dependências).
- [11 Testes Integração Supertest](./11%20Testes%20Integração%20Supertest): Escreva testes de integração com Supertest que testam os endpoints da API com banco real.
- [12 GraphQL Apollo](./12%20GraphQL%20Apollo): Converta a API REST para GraphQL usando Apollo Server com queries, mutations e subscriptions.
- [13 gRPC Server](./13%20gRPC%20Server): Crie um microserviço gRPC para gerenciar usuários com o protocolo Protobuf.
- [14 Swagger Documentação](./14%20Swagger%20Documentação): Documente a API usando Swagger/OpenAPI com validação de schema em runtime.
- [15 Cron Jobs](./15%20Cron%20Jobs): Agende tarefas recorrentes com node-cron: limpeza de sessões expiradas, envio de e-mails.
- [16 Clustering](./16%20Clustering): Use o módulo cluster do Node.js para aproveitar múltiplos núcleos de CPU na API.
- [17 Graceful Shutdown](./17%20Graceful%20Shutdown): Implemente graceful shutdown na API: finalize conexões abertas antes de encerrar o processo.
- [18 Streams Processamento](./18%20Streams%20Processamento): Crie um pipeline de Streams para processar e transformar um arquivo CSV de 1GB linha por linha.
- [19 Proxy Reverso](./19%20Proxy%20Reverso): Crie um proxy reverso simples que roteia requisições para diferentes microserviços.
- [20 API Gateway](./20%20API%20Gateway): Crie um API Gateway que autentique e roteia requisições para serviços downstream.
- [21 Passport Oauth](./21%20Passport%20Oauth): Implemente autenticação com OAuth 2.0 (Google/GitHub) usando Passport.js.
- [22 Email Nodemailer](./22%20Email%20Nodemailer): Envie e-mails com templates HTML usando Nodemailer e um serviço SMTP.
- [23 PDF Generator](./23%20PDF%20Generator): Gere PDFs de relatórios dinamicamente usando PDFKit ou Puppeteer.
- [24 Image Processing](./24%20Image%20Processing): Processe imagens (resize, crop, watermark) usando Sharp de forma assíncrona.
- [25 Crawler Cheerio](./25%20Crawler%20Cheerio): Crie um web crawler com Axios e Cheerio que extrai dados de uma página HTML.
- [26 Real Time Dashboard](./26%20Real%20Time%20Dashboard): Crie um dashboard em tempo real com Server-Sent Events (SSE) exibindo métricas do sistema.
- [27 Multi Tenancy](./27%20Multi%20Tenancy): Implemente multi-tenancy na API com isolamento de dados por subdomínio.
- [28 Event Driven Arch](./28%20Event%20Driven%20Arch): Refatore a API para uma arquitetura orientada a eventos usando o EventEmitter interno.
- [29 API Versioning](./29%20API%20Versioning): Implemente versionamento de API (/v1, /v2) com compatibilidade retroativa.
- [30 Health Checks](./30%20Health%20Checks): Implemente health checks detalhados (/health, /ready, /live) para uso com orquestradores.
