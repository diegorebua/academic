# Qualidade e Formatação de Código (ESLint, Prettier, Husky, Commitlint, SonarJS)

**O que é e qual o seu papel:** Automatização para impedir código ruim de subir, garantir um padrão visual (formatação) em todo o projeto e padronizar o histórico do Git.
**Tempo Estimado:** 3 a 5 dias

## Tópicos para Estudar
- [ ] O que é o Prettier e como ele se difere do ESLint (Formatação vs Qualidade)
- [ ] Como integrar ESLint e Prettier sem conflitos (`eslint-config-prettier`)
- [ ] Configurando as regras mais exigentes do ESLint no NestJS
- [ ] Setup do Husky + Lint-staged (rodar o Prettier e ESLint apenas nos arquivos modificados no pré-commit)
- [ ] Commitlint + Husky (`commit-msg` hook): Como forçar o padrão Conventional Commits (ex: `feat:`, `fix:`) nas mensagens de commit
- [ ] SonarJS/SonarQube: verificando cobertura de testes e code smells
