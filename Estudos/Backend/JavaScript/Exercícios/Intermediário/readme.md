# 🎯 JavaScript — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Todo List DOM](./01%20Todo%20List%20DOM): Crie uma To-Do List completa no navegador manipulando o DOM: adicionar, editar, remover e marcar como concluído.
- [02 Fetch ViaCEP](./02%20Fetch%20ViaCEP): Consuma a API do ViaCEP, exiba o endereço e salve o histórico de buscas no localStorage.
- [03 Jogo Da Velha](./03%20Jogo%20Da%20Velha): Crie um Jogo da Velha completo no navegador com indicação do vencedor e placar.
- [04 Carrossel](./04%20Carrossel): Implemente um carrossel de imagens com auto-play, botões de navegação e dots de posição.
- [05 Drag And Drop](./05%20Drag%20And%20Drop): Implemente um quadro Kanban simples usando a API de Drag and Drop nativa do HTML5.
- [06 Calculadora Avançada](./06%20Calculadora%20Avançada): Construa uma calculadora com histórico de operações, suporte a parênteses e memória (M+, M-, MR).
- [07 Debounce Throttle](./07%20Debounce%20Throttle): Implemente as funções debounce e throttle do zero e demonstre a diferença em um campo de busca.
- [08 Event Emitter](./08%20Event%20Emitter): Crie um EventEmitter customizado (similar ao do Node.js) com on, off, emit e once.
- [09 Promise All Settled](./09%20Promise%20All%20Settled): Crie um runner de tarefas que executa várias Promises e trata sucesso/falha de cada uma.
- [10 Async Await Retry](./10%20Async%20Await%20Retry): Implemente uma função que tenta executar uma operação assíncrona até N vezes com delay entre as tentativas.
- [11 Cache Simples](./11%20Cache%20Simples): Crie um sistema de cache em memória com tempo de expiração (TTL) para resultados de funções.
- [12 Observer Pattern](./12%20Observer%20Pattern): Implemente o padrão de projeto Observer para um sistema de notificações em tempo real.
- [13 Lazy Loading](./13%20Lazy%20Loading): Implemente Lazy Loading de imagens usando a Intersection Observer API.
- [14 Formulário Multistep](./14%20Formulário%20Multistep): Crie um formulário multi-etapas com validação em cada step e barra de progresso.
- [15 Infinite Scroll](./15%20Infinite%20Scroll): Implemente scroll infinito consumindo uma API paginada (ex: JSONPlaceholder).
- [16 Dark Mode](./16%20Dark%20Mode): Implemente alternância de Dark Mode com preferência salva no localStorage e respeito ao prefers-color-scheme.
- [17 Validação Form](./17%20Validação%20Form): Crie um formulário de cadastro com validação em tempo real de todos os campos (nome, email, CPF, senha forte).
- [18 Módulo Pattern](./18%20Módulo%20Pattern): Refatore um código procedural para usar o Module Pattern com IIFEs.
- [19 Currying](./19%20Currying): Implemente currying e composição de funções. Crie um pipeline funcional.
- [20 Prototype Chain](./20%20Prototype%20Chain): Demonstre herança via cadeia de protótipos. Crie classes sem usar a sintaxe ES6 class.
- [21 Intersection Observer](./21%20Intersection%20Observer): Use a Intersection Observer API para animar elementos conforme entram na viewport (scroll reveal).
- [22 Web Workers](./22%20Web%20Workers): Mova um cálculo pesado (ex: números primos até 10 milhões) para um Web Worker sem travar a UI.
- [23 Indexeddb](./23%20Indexeddb): Use a IndexedDB para criar um CRUD de contatos offline, sincronizando quando a conexão retornar.
- [24 Service Worker](./24%20Service%20Worker): Crie um Service Worker básico que cacheia os assets do site e permite acesso offline.
- [25 Websocket Chat](./25%20Websocket%20Chat): Crie um chat em tempo real simples usando WebSockets nativos (sem bibliotecas).
- [26 Canvas Jogo](./26%20Canvas%20Jogo): Crie um jogo simples no Canvas (ex: Pong ou Snake) com game loop e detecção de colisão.
- [27 Clone Trello](./27%20Clone%20Trello): Crie um clone simplificado do Trello com colunas e cartões arrastáveis, persistindo no localStorage.
- [28 Regex Parser](./28%20Regex%20Parser): Crie um mini parser de Markdown que converte **negrito**, *itálico* e # Títulos para HTML usando Regex.
- [29 Rate Limiter](./29%20Rate%20Limiter): Implemente um Rate Limiter no cliente que bloqueia requisições duplicadas em um intervalo de tempo.
- [30 Virtual DOM](./30%20Virtual%20DOM): Implemente um Virtual DOM minimalista com funções createElement, diff e patch.
