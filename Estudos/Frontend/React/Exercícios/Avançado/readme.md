# 🎯 React — Avançado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Renderização Server Side](./01%20Renderização%20Server%20Side): Implemente SSR com Next.js: getServerSideProps, getStaticProps e ISR.
- [02 React Server Components](./02%20React%20Server%20Components): Crie um app com React Server Components (RSC) para reduzir o JavaScript enviado ao cliente.
- [03 Concurrent Features](./03%20Concurrent%20Features): Use startTransition, useDeferredValue e Suspense para melhorar a responsividade.
- [04 Gerenciamento Estado Complexo](./04%20Gerenciamento%20Estado%20Complexo): Compare e implemente o mesmo estado com Redux, Zustand, Jotai e XState.
- [05 Micro Frontends React](./05%20Micro%20Frontends%20React): Integre múltiplos mini-apps React via Module Federation (Webpack 5).
- [06 Design System](./06%20Design%20System): Construa um design system com componentes base, tokens de design e Storybook.
- [07 Performance Profiling React](./07%20Performance%20Profiling%20React): Use o React DevTools Profiler para encontrar e corrigir gargalos de renderização.
- [08 Suspense Avançado](./08%20Suspense%20Avançado): Implemente Suspense com múltiplos níveis, fallbacks e data fetching integrado.
- [09 Custom Renderer](./09%20Custom%20Renderer): Crie um React Renderer customizado para um alvo diferente do DOM (ex: terminal, canvas).
- [10 Reconciler Internos](./10%20Reconciler%20Internos): Estude o reconciliador do React: como o Fiber funciona, prioridades e lanes.
- [11 Gerenciamento Formulário Avançado](./11%20Gerenciamento%20Formulário%20Avançado): Construa um engine de formulários dinâmicos que renderiza campos a partir de um JSON Schema.
- [12 Animações Physics](./12%20Animações%20Physics): Implemente animações baseadas em física com React Spring (molas, inércia).
- [13 3d React Three Fiber](./13%203d%20React%20Three%20Fiber): Crie uma cena 3D interativa com React Three Fiber (three.js + React).
- [14 Realtime Collaboration](./14%20Realtime%20Collaboration): Implemente edição colaborativa em tempo real (ex: editor de texto) com CRDTs e WebSockets.
- [15 Ab Testing](./15%20Ab%20Testing): Implemente um sistema de A/B testing em tempo de execução para componentes React.
- [16 Monorepo Turborepo](./16%20Monorepo%20Turborepo): Configure um monorepo com Turborepo, compartilhando componentes entre apps Next.js e Vite.
- [17 Edge Rendering](./17%20Edge%20Rendering): Deploy a aplicação no edge com Next.js Edge Runtime para latência mínima global.
- [18 Streaming SSR](./18%20Streaming%20SSR): Use Streaming SSR do React 18 para enviar HTML progressivamente ao cliente.
- [19 Islands Architecture](./19%20Islands%20Architecture): Implemente a Arquitetura de Ilhas com hidratação parcial usando Astro + React.
- [20 Accessibility Audit](./20%20Accessibility%20Audit): Faça uma auditoria completa de acessibilidade (WCAG 2.1 AA) e corrija todos os problemas.
- [21 Security React](./21%20Security%20React): Identifique e corrija vulnerabilidades XSS, CSRF e dependências inseguras em um app React.
- [22 Canvas React Performance](./22%20Canvas%20React%20Performance): Crie uma visualização de dados com Canvas API em React com dezenas de milhares de pontos.
- [23 WASM React](./23%20WASM%20React): Integre WebAssembly em React para uma tarefa de processamento pesado no cliente.
- [24 Redux Advanced Patterns](./24%20Redux%20Advanced%20Patterns): Implemente Entity Adapter, createListenerMiddleware e RTK Query no Redux Toolkit.
- [25 Query Normalization](./25%20Query%20Normalization): Normalize o cache de dados do React Query para evitar dados desatualizados.
- [26 Viewtransition API](./26%20Viewtransition%20API): Use a View Transition API para animações suaves entre páginas no React.
- [27 Signal Based React](./27%20Signal%20Based%20React): Implemente um mini framework de Signals que se integra com o ciclo de vida do React.
- [28 Shared Element Transition](./28%20Shared%20Element%20Transition): Implemente transições de elemento compartilhado entre rotas (ex: carta de produto que expande).
- [29 Offline First](./29%20Offline%20First): Construa uma aplicação offline-first com sync em background quando a conexão retornar.
- [30 Full Stack NextJS](./30%20Full%20Stack%20NextJS): Construa um app full-stack com Next.js App Router, Server Actions, Prisma e autenticação Auth.js.
