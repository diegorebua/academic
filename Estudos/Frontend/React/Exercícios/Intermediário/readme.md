# 🎯 React — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Gerenciamento useReducer](./01%20Gerenciamento%20useReducer): Substitua useState complexo por useReducer em um carrinho de compras.
- [02 Context Avançado](./02%20Context%20Avançado): Implemente um contexto de autenticação completo com login, logout e rota protegida.

- [09 Upload Imagem](./09%20Upload%20Imagem): Implemente upload de imagem com preview, drag-and-drop e barra de progresso.
- [10 Editor Markdown](./10%20Editor%20Markdown): Crie um editor de Markdown com preview em tempo real lado a lado.
- [11 Drag Drop Kanban](./11%20Drag%20Drop%20Kanban): Crie um quadro Kanban com drag-and-drop usando react-beautiful-dnd.
- [12 Gráficos Recharts](./12%20Gráficos%20Recharts): Implemente dashboards com gráficos de linha, barra e pizza usando Recharts.
- [13 Infinite Scroll React](./13%20Infinite%20Scroll%20React): Implemente scroll infinito com Intersection Observer e React Query.
- [14 Virtual List](./14%20Virtual%20List): Renderize uma lista de 100.000 itens eficientemente usando react-window.
- [15 Mapa Leaflet](./15%20Mapa%20Leaflet): Integre um mapa interativo com Leaflet e markers dinâmicos de uma API.
- [16 Real Time Websocket](./16%20Real%20Time%20Websocket): Integre WebSockets ao React para exibir notificações e dados em tempo real.
- [17 Autenticação Oauth](./17%20Autenticação%20Oauth): Implemente login social com Google usando @react-oauth/google.
- [18 PWA React](./18%20PWA%20React): Converta a aplicação React em uma PWA com Service Worker e manifest.json.
- [19 I18n Internacionalização](./19%20I18n%20Internacionalização): Adicione suporte a múltiplos idiomas usando react-i18next.
- [20 Testes React Testing Library](./20%20Testes%20React%20Testing%20Library): Escreva testes com React Testing Library e Jest para componentes e hooks.
- [21 Storybook Componentes](./21%20Storybook%20Componentes): Configure Storybook e documente seus componentes com stories interativos.
- [22 Zustand Estado Global](./22%20Zustand%20Estado%20Global): Migre o Context para Zustand em uma aplicação de médio porte.
- [23 Jotai Atoms](./23%20Jotai%20Atoms): Use Jotai para gerenciamento de estado atômico e reativo.
- [24 Code Splitting](./24%20Code%20Splitting): Implemente code splitting por rota e por componente para otimizar o bundle.
- [25 Web Vitals Otimização](./25%20Web%20Vitals%20Otimização): Meça e otimize as Core Web Vitals da aplicação (LCP, FID, CLS).
- [26 SWR Cache](./26%20SWR%20Cache): Use SWR para data fetching com revalidação, mutação e otimismo.
- [27 React Dnd Avançado](./27%20React%20Dnd%20Avançado): Implemente uma interface de criação de layouts com drag-and-drop multi-container.
- [28 Compound Components](./28%20Compound%20Components): Implemente o padrão Compound Components para um Select e um Tabs flexível.
- [29 Render Props Pattern](./29%20Render%20Props%20Pattern): Demonstre o padrão Render Props em componentes de mouse tracking e toggle.
- [30 Headless Components](./30%20Headless%20Components): Crie componentes Headless (sem estilo) usando Radix UI ou Headless UI.
