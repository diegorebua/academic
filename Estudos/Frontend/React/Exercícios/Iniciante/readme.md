# 🎯 React — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Contador](./01%20Contador): Crie um componente de contador com useState: incrementar, decrementar e resetar.
- [02 Lista De Tarefas](./02%20Lista%20De%20Tarefas): To-Do List simples: adicionar, remover e marcar tarefas como concluídas.
- [03 Renderização Listas](./03%20Renderização%20Listas): Renderize uma lista de itens de um array com .map() usando keys corretas.
- [04 Formulário Básico](./04%20Formulário%20Básico): Crie um formulário controlado com inputs de texto, select e checkbox.
- [05 Condicional Render](./05%20Condicional%20Render): Renderize componentes condicionalmente usando ternário, &&  e funções.
- [06 Props Básico](./06%20Props%20Básico): Passe props entre componentes pai e filho. Use PropTypes ou TypeScript para tipagem.
- [07 Eventos Básico](./07%20Eventos%20Básico): Trate eventos de clique, input e submit de forma idiomática no React.
- [08 Estilo CSS](./08%20Estilo%20CSS): Aplique estilos com CSS Modules, Styled Components e inline styles. Compare as abordagens.
- [09 useEffect Básico](./09%20useEffect%20Básico): Use useEffect para buscar dados de uma API ao montar o componente.
- [10 Componente Relogio](./10%20Componente%20Relogio): Crie um relógio que atualiza a cada segundo usando useState e useEffect com limpeza.
- [11 Galeria Fotos](./11%20Galeria%20Fotos): Crie uma galeria de fotos consumindo a API do Unsplash com lightbox ao clicar.
- [12 Formulário Cadastro](./12%20Formulário%20Cadastro): Formulário de cadastro com campos de nome, e-mail, senha e confirmação de senha.
- [13 Rating Estrelas](./13%20Rating%20Estrelas): Crie um componente de avaliação com estrelas clicáveis e hover.
- [14 Accordion](./14%20Accordion): Implemente um Accordion (sanfona) com múltiplos painéis que abrem e fecham.
- [15 Barra Progresso](./15%20Barra%20Progresso): Crie uma barra de progresso animada que pode ser controlada por props.
- [16 Carousel Simples](./16%20Carousel%20Simples): Implemente um carrossel de imagens com botões de navegação e auto-play.
- [17 Modal Dialog](./17%20Modal%20Dialog): Crie um componente Modal reutilizável com portal para renderizar fora da hierarquia.
- [18 Tooltip](./18%20Tooltip): Crie um componente Tooltip que aparece ao hoverar um elemento.
- [19 Dropdown Select](./19%20Dropdown%20Select): Crie um componente Select customizado com busca e opções dinâmicas.
- [20 Tabs Navegação](./20%20Tabs%20Navegação): Implemente um componente Tabs com navegação e conteúdo dinâmico.
- [21 Lazy Componente](./21%20Lazy%20Componente): Use React.lazy e Suspense para carregar componentes pesados sob demanda.
- [22 Error Boundary](./22%20Error%20Boundary): Crie um Error Boundary que exibe uma UI de fallback quando um componente filho lança um erro.
- [23 Fragment Portal](./23%20Fragment%20Portal): Demonstre o uso de React.Fragment e ReactDOM.createPortal.
- [24 Ref DOM](./24%20Ref%20DOM): Use useRef para acessar e manipular elementos do DOM diretamente (foco, scroll).
- [25 Forward Ref](./25%20Forward%20Ref): Implemente forwardRef em um componente Input para expor o ref ao componente pai.
- [26 Memo Componente](./26%20Memo%20Componente): Use React.memo para evitar re-renderizações desnecessárias em componentes filhos.
- [27 Context Tema](./27%20Context%20Tema): Use a Context API para compartilhar o tema (claro/escuro) em toda a aplicação.
- [28 Custom Hook Fetch](./28%20Custom%20Hook%20Fetch): Crie um custom hook useFetch que gerencia loading, data e error de uma requisição.
- [29 Pokedex Básica](./29%20Pokedex%20Básica): Crie uma Pokédex consumindo a PokeAPI com paginação e detalhes de cada Pokémon.
- [30 Portfolio Simples](./30%20Portfolio%20Simples): Crie um portfólio pessoal simples com React: seções de Sobre, Projetos e Contato.
