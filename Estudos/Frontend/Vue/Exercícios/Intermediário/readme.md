# 🎯 Vue — Intermediário

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Pinia Loja](./01%20Pinia%20Loja): Configure o Pinia e crie uma store para um carrinho de compras com persist.
- [02 Vue Router Avançado](./02%20Vue%20Router%20Avançado): Configure rotas aninhadas, guards de navegação e rotas com parâmetros dinâmicos.
- [03 Composables Custom](./03%20Composables%20Custom): Crie composables reutilizáveis: useFetch, useDebounce, useIntersectionObserver.
- [04 Formulário VeeValidate](./04%20Formulário%20VeeValidate): Implemente validação de formulário robusta com VeeValidate e Yup.
- [05 Componentes Async](./05%20Componentes%20Async): Use defineAsyncComponent para carregar componentes sob demanda com Suspense.
- [06 Teleport Vue](./06%20Teleport%20Vue): Use o componente <Teleport> para renderizar modais e tooltips fora da hierarquia do DOM.
- [07 Slots Avançados](./07%20Slots%20Avançados): Use named slots, scoped slots e o padrão renderless para componentes ultra-flexíveis.
- [08 Diretivas Customizadas](./08%20Diretivas%20Customizadas): Crie diretivas personalizadas v-focus, v-click-outside e v-tooltip.
- [09 Plugin Vue](./09%20Plugin%20Vue): Crie e registre um plugin Vue que adiciona propriedades globais e filtros.
- [10 SSR Nuxt Básico](./10%20SSR%20Nuxt%20Básico): Configure um projeto Nuxt.js com SSR, páginas, layouts e fetch de dados no servidor.
- [11 Testes Vitest](./11%20Testes%20Vitest): Escreva testes unitários com Vitest e Vue Test Utils para componentes e stores Pinia.
- [12 Storybook Vue](./12%20Storybook%20Vue): Configure Storybook e crie stories para seus componentes Vue.
- [13 Gráficos Vue ChartJS](./13%20Gráficos%20Vue%20ChartJS): Crie dashboards com gráficos usando Vue Chart.js (Chart.js wrapper).
- [14 Tabela DataTables](./14%20Tabela%20DataTables): Implemente uma tabela com paginação, ordenação e filtro server-side.
- [15 Maps Leaflet Vue](./15%20Maps%20Leaflet%20Vue): Integre Leaflet com Vue para exibir mapas com markers dinâmicos.
- [16 I18n Vue](./16%20I18n%20Vue): Configure internacionalização com vue-i18n e suporte a múltiplos idiomas.
- [17 Real Time Vue](./17%20Real%20Time%20Vue): Integre WebSockets via Socket.io para notificações em tempo real em Vue.
- [18 Autenticação Vue](./18%20Autenticação%20Vue): Implemente autenticação JWT com guarda de rotas e refresh de token automático.
- [19 Upload Vue](./19%20Upload%20Vue): Implemente upload de arquivos com preview usando vue-dropzone.
- [20 PDF Export](./20%20PDF%20Export): Gere PDFs de componentes Vue usando jsPDF e html2canvas.
- [21 Kanban Pinia](./21%20Kanban%20Pinia): Crie um quadro Kanban com drag-and-drop gerenciado pelo Pinia.
- [22 Editor Wysiwyg](./22%20Editor%20Wysiwyg): Integre um editor WYSIWYG (ex: Quill ou TipTap) em um formulário Vue.
- [23 PWA Vue](./23%20PWA%20Vue): Converta o app Vue em uma PWA com Service Worker usando vite-plugin-pwa.
- [24 SEO Nuxt](./24%20SEO%20Nuxt): Configure meta tags, Open Graph e sitemap no Nuxt.js para SEO.
- [25 Monorepo Vue](./25%20Monorepo%20Vue): Configure um monorepo com múltiplos apps Vue compartilhando componentes.
- [26 Renderização Virtual](./26%20Renderização%20Virtual): Implemente uma lista virtual com vue-virtual-scroller.
- [27 State Machine XState](./27%20State%20Machine%20XState): Use XState com Vue para gerenciar fluxos complexos (autenticação, wizard).
- [28 Animations GSAP](./28%20Animations%20GSAP): Integrate GSAP (GreenSock) com Vue para animações de alto desempenho.
- [29 Composable useFetch Avançado](./29%20Composable%20useFetch%20Avançado): Crie um composable useFetch avançado com cache, abort, retentativas e dedupliacação.
- [30 Design System Vue](./30%20Design%20System%20Vue): Construa um design system Vue com componentes documentados e publicável no npm.
