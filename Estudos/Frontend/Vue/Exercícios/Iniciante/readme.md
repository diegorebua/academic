# 🎯 Vue — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Contador Vue](./01%20Contador%20Vue): Crie um contador simples com ref() da Composition API.
- [02 Lista Tarefas Vue](./02%20Lista%20Tarefas%20Vue): To-Do List com v-model, v-for e v-if usando Composition API.
- [03 Formulário Controlado](./03%20Formulário%20Controlado): Crie um formulário controlado com v-model em inputs, selects e checkboxes.
- [04 Props Emits](./04%20Props%20Emits): Crie componentes pai e filho passando dados via props e respondendo via emits.
- [05 Computed Properties](./05%20Computed%20Properties): Use computed() para calcular valores derivados de forma reativa.
- [06 Watchers](./06%20Watchers): Use watch e watchEffect para reagir a mudanças de estado com efeitos colaterais.
- [07 Lifecycle Hooks](./07%20Lifecycle%20Hooks): Demonstre o uso de onMounted, onUpdated e onUnmounted com exemplos práticos.
- [08 V Model Custom](./08%20V%20Model%20Custom): Crie um componente Input customizado que funciona com v-model externo.
- [09 Slots Simples](./09%20Slots%20Simples): Use slots para criar componentes contêiner flexíveis (Card, Modal, Layout).
- [10 Diretivas Vue](./10%20Diretivas%20Vue): Use v-show, v-if, v-else, v-for, v-bind e v-on em exemplos variados.
- [11 Template Refs](./11%20Template%20Refs): Use template refs para acessar elementos do DOM e métodos de componentes filhos.
- [12 Provide Inject](./12%20Provide%20Inject): Use provide/inject para compartilhar dados entre componentes sem props drilling.
- [13 Reactive Object](./13%20Reactive%20Object): Compare ref() e reactive() e entenda quando usar cada um.
- [14 Consumir API Axios](./14%20Consumir%20API%20Axios): Consuma a API do JSONPlaceholder usando Axios dentro do onMounted.
- [15 Galeria Imagens](./15%20Galeria%20Imagens): Crie uma galeria de imagens com lightbox usando componentes Vue.
- [16 Filtros Busca](./16%20Filtros%20Busca): Crie uma lista filtrável com computed properties e um campo de busca.
- [17 Carrinho Simples](./17%20Carrinho%20Simples): Implemente um carrinho de compras simples com reactividade e total calculado.
- [18 Dark Mode Vue](./18%20Dark%20Mode%20Vue): Implemente alternância de tema claro/escuro com provide/inject.
- [19 Animações Transição](./19%20Animações%20Transição): Use as diretivas <Transition> e <TransitionGroup> para animar listas e componentes.
- [20 Validação Formulário](./20%20Validação%20Formulário): Valide um formulário manualmente e depois com a biblioteca Vuelidate.
- [21 Roteamento Básico](./21%20Roteamento%20Básico): Configure o Vue Router com rotas simples e navegação entre páginas.
- [22 Paginação Lista](./22%20Paginação%20Lista): Implemente paginação manual em uma lista de dados.
- [23 Barra Progresso Vue](./23%20Barra%20Progresso%20Vue): Crie uma barra de progresso animada controlada por estado reativo.
- [24 Accordion Vue](./24%20Accordion%20Vue): Implemente um Accordion com componentes aninhados.
- [25 Breadcrumb Router](./25%20Breadcrumb%20Router): Crie um componente de Breadcrumb dinâmico integrado com o Vue Router.
- [26 Infinite Scroll Vue](./26%20Infinite%20Scroll%20Vue): Implemente scroll infinito usando Intersection Observer e dados de uma API.
- [27 Drag Drop Simples](./27%20Drag%20Drop%20Simples): Implemente drag-and-drop simples usando eventos de drag nativos do HTML5.
- [28 Clipboard API](./28%20Clipboard%20API): Crie um botão de 'Copiar para área de transferência' com feedback visual.
- [29 Composable useLocalStorage](./29%20Composable%20useLocalStorage): Crie um composable useLocalStorage que sincroniza estado com o localStorage.
- [30 Mini Portfolio Vue](./30%20Mini%20Portfolio%20Vue): Crie um mini portfólio pessoal com Vue.js: seções de Sobre, Projetos e Contato.
