# 🎯 Vue — Avançado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Server Components Nuxt](./01%20Server%20Components%20Nuxt): Explore os Nuxt Server Components e Island Components para hidratação parcial.
- [02 Custom Renderer Vue](./02%20Custom%20Renderer%20Vue): Crie um renderer customizado do Vue para um alvo diferente (ex: canvas, terminal).
- [03 Reactivity Internals](./03%20Reactivity%20Internals): Explore a API de reatividade interna do Vue 3: effect, track, trigger, ref customizado.
- [04 Compilador Vue](./04%20Compilador%20Vue): Explore o compilador do Vue: transformações de template para render functions.
- [05 Vapor Mode](./05%20Vapor%20Mode): Explore o modo Vapor do Vue (sem Virtual DOM) e compare a performance.
- [06 Micro Frontends Vue](./06%20Micro%20Frontends%20Vue): Implemente uma arquitetura de Micro Frontends com Vue e Module Federation.
- [07 SSR Streaming Nuxt](./07%20SSR%20Streaming%20Nuxt): Configure Streaming SSR no Nuxt para enviar HTML progressivamente.
- [08 Edge Rendering Nuxt](./08%20Edge%20Rendering%20Nuxt): Deploy do Nuxt no edge com Cloudflare Workers ou Deno Deploy.
- [09 Offline First Vue](./09%20Offline%20First%20Vue): Construa um app offline-first com sincronização em background usando Workbox.
- [10 Collaborative Editing](./10%20Collaborative%20Editing): Implemente edição colaborativa com CRDTs (Yjs) integrados ao Vue.
- [11 Performance Audit Vue](./11%20Performance%20Audit%20Vue): Audite e otimize um app Vue: bundle size, tree shaking, lazy loading e renderização.
- [12 Accessibility Vue](./12%20Accessibility%20Vue): Realize uma auditoria completa de acessibilidade no app e corrija todos os problemas.
- [13 Plugin Avançado Vue](./13%20Plugin%20Avançado%20Vue): Crie um plugin Vue avançado que integra um serviço externo (ex: analytics, feature flags).
- [14 Metaframework Criação](./14%20Metaframework%20Criação): Crie um mini meta-framework inspirado no Nuxt usando Vite, Vue 3 e file-based routing.
- [15 Vite Plugin Vue](./15%20Vite%20Plugin%20Vue): Crie um plugin Vite customizado que transforma arquivos .vue em tempo de build.
- [16 Suspense Error Boundary](./16%20Suspense%20Error%20Boundary): Implemente Suspense e ErrorBoundary avançados com múltiplos níveis e streaming.
- [17 Form Engine](./17%20Form%20Engine): Construa um engine de formulários dinâmicos que gera campos a partir de JSON Schema.
- [18 Monorepo Turborepo Vue](./18%20Monorepo%20Turborepo%20Vue): Configure um monorepo Turborepo com apps Nuxt e Vue compartilhando código.
- [19 Architecture Ddd Vue](./19%20Architecture%20Ddd%20Vue): Aplique DDD no frontend Vue: separação de domínio, repositórios e casos de uso.
- [20 Testing Advanced Vue](./20%20Testing%20Advanced%20Vue): Implemente testes de componentes, E2E com Playwright e testes de contrato.
- [21 Devtools Plugin](./21%20Devtools%20Plugin): Crie um plugin para o Vue DevTools que exibe informações customizadas.
- [22 Schema Driven UI](./22%20Schema%20Driven%20UI): Construa uma UI completamente dirigida por schema JSON, renderizando formulários e listas.
- [23 Signal Integration](./23%20Signal%20Integration): Integre a biblioteca de Signals (@vue/signals ou alien-signals) ao Vue 3.
- [24 Dependency Injection Vue](./24%20Dependency%20Injection%20Vue): Implemente um contêiner de Injeção de Dependências usando provide/inject de forma avançada.
- [25 Ab Testing Vue](./25%20Ab%20Testing%20Vue): Implemente A/B testing no nível de componentes Vue com targeting de usuários.
- [26 WASM Vue](./26%20WASM%20Vue): Integre WebAssembly em Vue para processamento pesado no cliente.
- [27 Web Components Vue](./27%20Web%20Components%20Vue): Converta componentes Vue em Web Components nativos usando defineCustomElement.
- [28 View Transitions Vue](./28%20View%20Transitions%20Vue): Use a View Transition API com o Vue Router para animações suaves entre páginas.
- [29 Full Stack Nuxt](./29%20Full%20Stack%20Nuxt): Construa um app full-stack com Nuxt 3: server routes, Nitro, banco de dados e autenticação.
- [30 Oss Library Vue](./30%20Oss%20Library%20Vue): Crie e publique uma biblioteca de componentes Vue open-source no npm com CI/CD.
