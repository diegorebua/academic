# Estudos Técnicos

Base pessoal de conhecimento técnico.

O objetivo é registrar conceitos encontrados no trabalho, entender onde eles se encaixam e aprofundá-los depois, sem interromper o fluxo.

## Como usar

1. Encontrou um conceito novo.
2. Classifique na área certa.
3. Faça uma nota curta.
4. Continue trabalhando.
5. Aprofunde depois, se o assunto voltar a aparecer.
