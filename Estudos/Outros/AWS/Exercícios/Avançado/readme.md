# 🎯 AWS — Avançado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Landing Zone](./01%20Landing%20Zone): Configure uma Landing Zone multi-conta com AWS Control Tower e Account Factory.
- [02 Service Control Policies](./02%20Service%20Control%20Policies): Implemente SCPs para restringir ações em toda a organização (ex: bloquear regiões não aprovadas).
- [03 Terraform Modules](./03%20Terraform%20Modules): Crie módulos Terraform reutilizáveis para VPC, ECS e RDS com variáveis e outputs.
- [04 Terraform Remote State](./04%20Terraform%20Remote%20State): Configure Terraform com state remoto no S3, bloqueio via DynamoDB e workspaces.
- [05 Cdk Infraestrutura](./05%20Cdk%20Infraestrutura): Provisione uma infraestrutura completa usando AWS CDK em TypeScript.
- [06 Serverless Avançado](./06%20Serverless%20Avançado): Crie uma aplicação Serverless complexa com API Gateway, Lambda, DynamoDB e SQS com SAM.
- [07 Ecs Service Mesh](./07%20Ecs%20Service%20Mesh): Configure AWS App Mesh como service mesh para comunicação entre serviços ECS.
- [08 Eks Kubernetes](./08%20Eks%20Kubernetes): Provisione um cluster EKS, deploye uma aplicação e configure HPA.
- [09 Multi Region Active Active](./09%20Multi%20Region%20Active%20Active): Projete e implemente um sistema Active-Active multi-região com Route 53 geolocation routing.
- [10 Chaos Engineering AWS](./10%20Chaos%20Engineering%20AWS): Use o AWS Fault Injection Service (FIS) para injetar falhas e testar resiliência.
- [11 Data Lake S3](./11%20Data%20Lake%20S3): Construa um Data Lake no S3 com camadas Bronze, Silver e Gold e governança com Glue.
- [12 Realtime Analytics](./12%20Realtime%20Analytics): Implemente analytics em tempo real com Kinesis Data Streams → Flink → OpenSearch.
- [13 Ml Sagemaker](./13%20Ml%20Sagemaker): Treine e faça deploy de um modelo de ML simples com SageMaker Pipelines.
- [14 Bedrock Integration](./14%20Bedrock%20Integration): Integre o Amazon Bedrock (LLMs) em uma aplicação serverless para geração de texto.
- [15 Zero Trust AWS](./15%20Zero%20Trust%20AWS): Implemente Zero Trust na AWS: mTLS, Verified Access e least-privilege estrito.
- [16 Supply Chain Security](./16%20Supply%20Chain%20Security): Configure assinatura de imagens Docker com Notary e verificação no ECR.
- [17 VPC Lattice](./17%20VPC%20Lattice): Use o VPC Lattice para comunicação segura e simplificada entre serviços.
- [18 Graviton Arm](./18%20Graviton%20Arm): Migre cargas de trabalho para instâncias Graviton3 (ARM) e meça a economia de custo.
- [19 Finops Avançado](./19%20Finops%20Avançado): Implemente FinOps: tagging strategy, chargeback reports e automação de rightsizing.
- [20 Well Architected Remediação](./20%20Well%20Architected%20Remediação): Realize um Well-Architected Review completo e implemente os 10 principais remediações.
- [21 Security Hub SIEM](./21%20Security%20Hub%20SIEM): Centralize alertas de segurança com Security Hub e integre com um SIEM (ex: Splunk).
- [22 Custom Lens](./22%20Custom%20Lens): Crie um Custom Lens no Well-Architected Tool para as especificidades da sua empresa.
- [23 Config Remediation](./23%20Config%20Remediation): Configure remediação automática no AWS Config com SSM Automation Documents.
- [24 Private API Gateway](./24%20Private%20API%20Gateway): Configure um API Gateway privado acessível apenas dentro da VPC via VPC Endpoint.
- [25 Transit Gateway](./25%20Transit%20Gateway): Configure o Transit Gateway para conectar múltiplas VPCs e redes on-premises.
- [26 Direct Connect Simulado](./26%20Direct%20Connect%20Simulado): Simule uma conexão Direct Connect usando VPN como failover em uma arquitetura híbrida.
- [27 RDS Proxy](./27%20RDS%20Proxy): Configure o RDS Proxy para pooling de conexões e failover mais rápido.
- [28 Aurora Serverless](./28%20Aurora%20Serverless): Use Aurora Serverless v2 e explore seu scaling automático e global database.
- [29 Memorydb Redis](./29%20Memorydb%20Redis): Migre do ElastiCache Redis para o MemoryDB e explore a durabilidade com Multi-AZ.
- [30 Architecture Review Completo](./30%20Architecture%20Review%20Completo): Proponha e documente a arquitetura completa de um sistema de e-commerce de alta escala na AWS.
