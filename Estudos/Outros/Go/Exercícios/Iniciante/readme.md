# 🎯 Go — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Hello World](./01%20Hello%20World): Escreva um programa que imprime 'Olá, Mundo!' e lê o nome do usuário com fmt.Scan.
- [02 Tipos Variáveis](./02%20Tipos%20Variáveis): Declare variáveis com todos os tipos básicos do Go: int, float64, string, bool, byte, rune.
- [03 Estruturas Controle](./03%20Estruturas%20Controle): Use if/else, for e switch em exemplos práticos (FizzBuzz, calculadora de notas).
- [04 Funções Básicas](./04%20Funções%20Básicas): Crie funções com múltiplos retornos. Implemente troca de valores e divisão com resto.
- [05 Arrays Slices](./05%20Arrays%20Slices): Diferenças entre arrays e slices. Manipule slices com append, copy e slice expressions.
- [06 Maps Básicos](./06%20Maps%20Básicos): Crie e manipule maps. Conte frequência de palavras em um texto.
- [07 Structs Métodos](./07%20Structs%20Métodos): Crie structs para Formas (Círculo, Retângulo) e métodos para calcular área e perímetro.
- [08 Interfaces Básicas](./08%20Interfaces%20Básicas): Defina uma interface Animal com métodos Falar() e Mover(). Implemente com Cachorro e Pássaro.
- [09 Ponteiros](./09%20Ponteiros): Entenda ponteiros em Go: desreferenciar, passar por ponteiro e quando usar.
- [10 Tratamento Erros](./10%20Tratamento%20Erros): Implemente tratamento de erros idiomático com error, fmt.Errorf e errors.Is/As.
- [11 Goroutine Simples](./11%20Goroutine%20Simples): Crie goroutines simples com go func() e sincronize com WaitGroup.
- [12 Channels Básicos](./12%20Channels%20Básicos): Crie channels buffered e unbuffered para comunicar goroutines.
- [13 Defer Panic Recover](./13%20Defer%20Panic%20Recover): Demonstre defer para limpeza de recursos, e panic/recover para situações excepcionais.
- [14 Leitura Arquivo](./14%20Leitura%20Arquivo): Leia um arquivo texto linha por linha usando bufio.Scanner.
- [15 Escrita Arquivo](./15%20Escrita%20Arquivo): Escreva dados em arquivo usando os.WriteFile e bufio.Writer.
- [16 Conversão Tipos](./16%20Conversão%20Tipos): Pratique conversões entre int, float64, string e []byte.
- [17 Fibonacci Go](./17%20Fibonacci%20Go): Gere a sequência de Fibonacci usando iteração e depois com goroutines e channels.
- [18 Ordenação Slice](./18%20Ordenação%20Slice): Ordene slices de strings, ints e structs usando sort.Slice e sort.SliceStable.
- [19 Manipulação String](./19%20Manipulação%20String): Use strings.Builder, strings.Split, strings.Join e regexp para processar textos.
- [20 JSON Marshal Unmarshal](./20%20JSON%20Marshal%20Unmarshal): Serialize e desserialize structs Go para/de JSON. Trate campos opcionais.
- [21 Calculator CLI Go](./21%20Calculator%20CLI%20Go): Crie uma calculadora de linha de comando usando os.Args e fmt.Sscanf.
- [22 Validador Cpf Go](./22%20Validador%20Cpf%20Go): Implemente a validação de CPF em Go usando apenas operações matemáticas.
- [23 Contagem Palavras](./23%20Contagem%20Palavras): Leia um arquivo de texto e exiba as 10 palavras mais frequentes.
- [24 Gerador Senha Go](./24%20Gerador%20Senha%20Go): Crie um gerador de senhas aleatórias usando crypto/rand.
- [25 HTTP Get Simples](./25%20HTTP%20Get%20Simples): Faça uma requisição HTTP GET usando net/http e processe a resposta JSON.
- [26 Busca Binária Go](./26%20Busca%20Binária%20Go): Implemente busca binária e linear e compare usando benchmarks com testing.B.
- [27 Fibonacci Memo Go](./27%20Fibonacci%20Memo%20Go): Implemente Fibonacci com memoização usando map e com closures.
- [28 Pilha Fila Go](./28%20Pilha%20Fila%20Go): Implemente Pilha e Fila em Go usando slices.
- [29 Anagrama Go](./29%20Anagrama%20Go): Verifique se duas strings são anagramas usando runas para suporte a Unicode.
- [30 Temperatura Converter Go](./30%20Temperatura%20Converter%20Go): Crie um conversor de temperatura CLI que aceita bandeiras com flag package.
