# 🎯 Go — Avançado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Clean Arch Go](./01%20Clean%20Arch%20Go): Implemente Clean Architecture em Go: Domain, Use Cases, Interface Adapters, Frameworks.
- [02 Ddd Go](./02%20Ddd%20Go): Modele um domínio bancário com DDD: Aggregates, Entities, Value Objects e Domain Events.
- [03 Event Sourcing Go](./03%20Event%20Sourcing%20Go): Implemente Event Sourcing com EventStore e replay de eventos para reconstruir estado.
- [04 Saga Go](./04%20Saga%20Go): Implemente o padrão Saga para uma transação distribuída de compra com compensação.
- [05 Kafka Go](./05%20Kafka%20Go): Produza e consuma mensagens no Kafka usando confluent-kafka-go com grupos de consumo.
- [06 Raft Consensus](./06%20Raft%20Consensus): Implemente o algoritmo de consenso Raft simplificado em Go usando goroutines.
- [07 Scheduler Distribuído](./07%20Scheduler%20Distribuído): Crie um scheduler distribuído tolerante a falhas usando etcd para eleição de líder.
- [08 Custom Garbage Collector](./08%20Custom%20Garbage%20Collector): Implemente um alocador de memória simples com garbage collection por referência.
- [09 Assembly Go](./09%20Assembly%20Go): Escreva funções em assembly x86-64 chamadas a partir do Go para operações SIMD.
- [10 Network Raw Socket](./10%20Network%20Raw%20Socket): Use raw sockets para criar um scanner de portas TCP (similar ao nmap) do zero.
- [11 Compiler Go](./11%20Compiler%20Go): Crie um compilador de uma linguagem simples usando o toolchain Go (go/parser, go/ast).
- [12 Cgo Integração](./12%20Cgo%20Integração): Integre código C em Go com cgo: chame funções C e passe structs entre as duas linguagens.
- [13 WASM Go](./13%20WASM%20Go): Compile um programa Go para WebAssembly e integre-o em uma página HTML.
- [14 Distributed Lock](./14%20Distributed%20Lock): Implemente um Distributed Lock usando Redis (Redlock algorithm).
- [15 Service Mesh Sidecar](./15%20Service%20Mesh%20Sidecar): Implemente um sidecar proxy em Go para interceptar e logar tráfego de rede.
- [16 Consensus Paxos](./16%20Consensus%20Paxos): Implemente o algoritmo Paxos (single-decree) em Go para entender consenso distribuído.
- [17 LSM Tree](./17%20LSM%20Tree): Implemente um LSM-Tree (Log-Structured Merge-Tree) simplificado: MemTable e SSTable.
- [18 B Tree Go](./18%20B%20Tree%20Go): Implemente uma B-Tree em Go com inserção, busca e deleção.
- [19 Query Engine](./19%20Query%20Engine): Crie um query engine SQL simplificado que analisa e executa SELECTs básicos.
- [20 Bloom Filter](./20%20Bloom%20Filter): Implemente um Bloom Filter probabilístico e use-o para verificar membership.
- [21 Hyperloglog Go](./21%20Hyperloglog%20Go): Implemente o algoritmo HyperLogLog para estimativa de cardinalidade.
- [22 Circuit Breaker Go](./22%20Circuit%20Breaker%20Go): Implemente Circuit Breaker com estados e transições em Go para chamadas de serviços.
- [23 Zero Copy Go](./23%20Zero%20Copy%20Go): Use técnicas de zero-copy (sendfile, splice) para transferência eficiente de arquivos.
- [24 Lock Free Structures](./24%20Lock%20Free%20Structures): Implemente estruturas lock-free (fila MPMC) usando sync/atomic.
- [25 Custom TCP Protocol](./25%20Custom%20TCP%20Protocol): Defina e implemente um protocolo TCP binário customizado (framing, encoding, handling).
- [26 Distributed Cache](./26%20Distributed%20Cache): Construa um cache distribuído consistente com hashing consistente e replicação.
- [27 Tracing OpenTelemetry Go](./27%20Tracing%20OpenTelemetry%20Go): Configure distributed tracing com OpenTelemetry e exporte para Jaeger.
- [28 Mutation Testing Go](./28%20Mutation%20Testing%20Go): Configure mutation testing com go-mutesting para verificar a qualidade dos testes.
- [29 Generics Advanced](./29%20Generics%20Advanced): Explore os limites dos generics em Go: constraints complexas, type sets e instâncias.
- [30 Interpreter Go](./30%20Interpreter%20Go): Implemente um interpretador completo (lexer, parser, avaliador) para uma linguagem de script.
