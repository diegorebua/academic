# 🎯 Java — Avançado

- [17 JMH Benchmarks](./17%20JMH%20Benchmarks): Use JMH (Java Microbenchmark Harness) para medir e comparar performance de código.
- [18 Java Agent](./18%20Java%20Agent): Crie um Java Agent para instrumentação em tempo de execução (AOP sem framework).
- [19 Bytecode Manipulation](./19%20Bytecode%20Manipulation): Use Byte Buddy ou ASM para manipular bytecode Java em runtime.
- [20 Panama Foreign](./20%20Panama%20Foreign): Use o Project Panama (Java 22+) para chamar bibliotecas nativas sem JNI.
- [21 Structured Concurrency](./21%20Structured%20Concurrency): Use Structured Concurrency (Java 21+) para gerenciar grupos de tarefas relacionadas.
- [22 Scoped Values](./22%20Scoped%20Values): Use Scoped Values (Java 21+) como alternativa segura ao ThreadLocal.
- [23 JIT Analysis](./23%20JIT%20Analysis): Analise o código gerado pelo JIT usando JITWatch e otimize hot paths.
- [24 Distributed Tracing Java](./24%20Distributed%20Tracing%20Java): Configure Distributed Tracing com Micrometer Tracing e Zipkin em microserviços.
- [25 Resilience4j](./25%20Resilience4j): Configure Resilience4j: Circuit Breaker, Retry, Bulkhead e Rate Limiter.
- [26 Chaos Monkey Spring](./26%20Chaos%20Monkey%20Spring): Use Chaos Monkey for Spring Boot para injetar falhas em produção de forma controlada.
- [27 Contract Testing Java](./27%20Contract%20Testing%20Java): Implemente Consumer-Driven Contract Testing com Pact entre microserviços Java.
- [28 Clean Code Refactoring](./28%20Clean%20Code%20Refactoring): Refatore um código legado aplicando os princípios SOLID e Clean Code.
- [29 Quarkus App](./29%20Quarkus%20App): Migre uma aplicação Spring Boot para Quarkus e compare startup time e uso de memória.
- [30 System Design Java](./30%20System%20Design%20Java): Projete e implemente um serviço de encurtamento de URL escalável: design, código e testes.
