# 🎯 Java — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Hello World Java](./01%20Hello%20World%20Java): Escreva o programa 'Olá, Mundo!' e entenda a estrutura básica: classe, main, System.out.
- [02 Tipos Primitivos](./02%20Tipos%20Primitivos): Explore todos os tipos primitivos (int, long, double, char, boolean) e seus wrappers.
- [03 Estruturas Controle Java](./03%20Estruturas%20Controle%20Java): Use if/else, switch, for, while e do-while em exemplos práticos.
- [04 Arrays Java](./04%20Arrays%20Java): Crie e manipule arrays unidimensionais e bidimensionais. Calcule média e maior/menor.
- [05 Strings Java](./05%20Strings%20Java): Explore os métodos da classe String: split, join, replace, format, compareTo.
- [06 POO Básico](./06%20POO%20Básico): Crie classes Conta e Cliente com atributos, construtores e métodos de depósito/saque.
- [07 Herança Java](./07%20Herança%20Java): Implemente herança: Veiculo → Carro, Moto. Override de métodos.
- [08 Interface Java](./08%20Interface%20Java): Crie uma interface Pagavel com métodos calcularJuros() e pagar(). Implemente com Boleto e CartaoCredito.
- [09 Encapsulamento](./09%20Encapsulamento): Aplique encapsulamento com modificadores de acesso (private, protected) e getters/setters.
- [10 Coleções Java](./10%20Coleções%20Java): Use ArrayList, LinkedList, HashSet e TreeSet. Compare desempenho e casos de uso.
- [11 Maps Java](./11%20Maps%20Java): Use HashMap e TreeMap para mapear chave-valor. Contar frequência de palavras.
- [12 Exceções Java](./12%20Exceções%20Java): Trate exceções com try-catch-finally. Crie exceções customizadas para domínio.
- [13 Generics Java](./13%20Generics%20Java): Crie classes e métodos genéricos. Implemente um Container<T> e Pilha<T>.
- [14 Enum Java](./14%20Enum%20Java): Crie Enums com atributos e métodos para representar os planetas do sistema solar.
- [15 Record Java](./15%20Record%20Java): Use Records (Java 14+) para criar objetos de dados imutáveis.
- [16 Optional Java](./16%20Optional%20Java): Use Optional<T> para evitar NullPointerException. Compare com abordagem tradicional.
- [17 Lambda Simples](./17%20Lambda%20Simples): Escreva lambdas para Comparator, Runnable e interfaces funcionais simples.
- [18 Streams Simples](./18%20Streams%20Simples): Use filter, map e collect na Stream API para processar uma lista de objetos.
- [19 Local Date Time](./19%20Local%20Date%20Time): Manipule datas com LocalDate, LocalDateTime e DateTimeFormatter (Java 8+).
- [20 Files Java](./20%20Files%20Java): Leia e escreva arquivos com java.nio.file.Files e Paths.
- [21 Scanner Input](./21%20Scanner%20Input): Use Scanner para ler diferentes tipos de entrada do usuário no console.
- [22 String Builder](./22%20String%20Builder): Compare String, StringBuilder e StringBuffer em operações de concatenação.
- [23 Autoboxing](./23%20Autoboxing): Demonstre autoboxing e unboxing e os cuidados com NullPointerException e performance.
- [24 Varargs](./24%20Varargs): Use varargs para criar métodos que aceitam número variável de argumentos.
- [25 Nested Inner Class](./25%20Nested%20Inner%20Class): Explore inner classes, classes anônimas e static nested classes.
- [26 Iterator Pattern](./26%20Iterator%20Pattern): Implemente o padrão Iterator em uma coleção customizada.
- [27 Fibonacci Java](./27%20Fibonacci%20Java): Implemente Fibonacci com recursão simples, com memoização e com streams infinitas.
- [28 Palíndromo Java](./28%20Palíndromo%20Java): Verifique palíndromo ignorando espaços, pontuação e maiúsculas.
- [29 Calculadora Java](./29%20Calculadora%20Java): Crie uma calculadora com padrão Strategy: cada operação é uma classe separada.
- [30 Jogo Adivinhar Java](./30%20Jogo%20Adivinhar%20Java): Crie o jogo de adivinhar o número com tentativas limitadas e dicas de maior/menor.
