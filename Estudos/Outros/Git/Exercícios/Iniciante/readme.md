# 🎯 Git — Iniciante

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Configuração Inicial](./01%20Configuração%20Inicial): Configure nome, e-mail, editor padrão e aliases úteis no Git (git config global).
- [02 Init Primeiro Commit](./02%20Init%20Primeiro%20Commit): Inicie um repositório, crie arquivos, faça staging e o primeiro commit.
- [03 Status Log Diff](./03%20Status%20Log%20Diff): Explore git status, git log (--oneline, --graph), git diff e git show.
- [04 Gitignore](./04%20Gitignore): Crie um .gitignore completo para um projeto Node.js. Entenda os padrões glob.
- [05 Staging Area](./05%20Staging%20Area): Entenda a staging area: git add -p para adicionar partes de um arquivo, git reset HEAD.
- [06 Branching Básico](./06%20Branching%20Básico): Crie branches com git branch e git checkout/switch. Entenda HEAD e as referências.
- [07 Merge Fastforward](./07%20Merge%20Fastforward): Faça merge de uma feature branch (fast-forward). Veja o histórico resultante.
- [08 Merge Commit](./08%20Merge%20Commit): Force um merge commit (--no-ff). Compare o histórico com o fast-forward.
- [09 Resolução Conflitos Básica](./09%20Resolução%20Conflitos%20Básica): Simule um conflito de merge alterando a mesma linha e resolva manualmente.
- [10 Stash Básico](./10%20Stash%20Básico): Use git stash para salvar mudanças temporárias, trocar de branch e restaurar.
- [11 Remote Github](./11%20Remote%20Github): Conecte o repositório ao GitHub: git remote add, push, pull e fetch.
- [12 Clone Fork](./12%20Clone%20Fork): Clone um repositório público e entenda a diferença entre clone e fork.
- [13 Pull Request Básico](./13%20Pull%20Request%20Básico): Crie uma feature branch, faça push e abra um Pull Request no GitHub.
- [14 Tags Versioning](./14%20Tags%20Versioning): Crie tags anotadas e leves para marcar versões do projeto (v1.0.0, v1.1.0).
- [15 Amend Commit](./15%20Amend%20Commit): Use git commit --amend para corrigir a mensagem ou adicionar arquivos ao último commit.
- [16 Gitconfig Aliases](./16%20Gitconfig%20Aliases): Configure aliases úteis: git st, git co, git lg, git undo.
- [17 Reverter Mudanças](./17%20Reverter%20Mudanças): Use git restore para descartar mudanças no working directory e staging.
- [18 Branch Upstream](./18%20Branch%20Upstream): Configure branches de rastreamento (tracking branches) para push/pull sem argumentos.
- [19 Visualizar Histórico](./19%20Visualizar%20Histórico): Use git log com filtros: --author, --since, --grep, --all, -S 'string'.
- [20 Arquivo Histórico](./20%20Arquivo%20Histórico): Use git blame para ver quem modificou cada linha e git log -- path para o histórico de um arquivo.
- [21 Cherry Pick Simples](./21%20Cherry%20Pick%20Simples): Traga um commit específico de outra branch com git cherry-pick.
- [22 Submódulos Básico](./22%20Submódulos%20Básico): Adicione um repositório como submódulo e entenda como atualizar e commitar.
- [23 Worktree](./23%20Worktree): Use git worktree para trabalhar em duas branches ao mesmo tempo em diretórios separados.
- [24 Bundle Backup](./24%20Bundle%20Backup): Crie um backup completo do repositório com git bundle.
- [25 Sparse Checkout](./25%20Sparse%20Checkout): Use git sparse-checkout para checar apenas parte de um repositório grande.
- [26 Commit Message Convention](./26%20Commit%20Message%20Convention): Adote Conventional Commits: feat, fix, docs, chore, refactor, test.
- [27 Merge Vs Rebase Conceito](./27%20Merge%20Vs%20Rebase%20Conceito): Entenda conceitualmente a diferença entre merge e rebase com diagramas.
- [28 Git Shortlog](./28%20Git%20Shortlog): Use git shortlog -sn para ver a contribuição de cada autor.
- [29 Git Describe](./29%20Git%20Describe): Use git describe para gerar versões automaticamente baseadas em tags.
- [30 Primeiro Open Source](./30%20Primeiro%20Open%20Source): Faça um fork de um repositório open-source, corrija um bug simples e abra um PR.
