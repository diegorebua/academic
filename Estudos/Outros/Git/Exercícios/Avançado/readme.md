# 🎯 Git — Avançado

**Total de exercícios neste nível:** 30

## 📝 Lista de Exercícios

- [01 Git Plumbing](./01%20Git%20Plumbing): Use os comandos de encanamento (plumbing) do Git: hash-object, cat-file, write-tree, commit-tree.
- [02 Reimplementar Git](./02%20Reimplementar%20Git): Implemente um mini Git do zero em Python ou Go: init, hash-object, cat-file, add, commit.
- [03 Custom Merge Driver](./03%20Custom%20Merge%20Driver): Crie um merge driver customizado para arquivos que o Git não sabe mesclar (ex: JSON).
- [04 Custom Diff Driver](./04%20Custom%20Diff%20Driver): Crie um diff driver customizado para exibir diferenças semânticas em arquivos binários.
- [05 Grafts Replace](./05%20Grafts%20Replace): Use git replace para criar grafos de commits alternativos sem modificar o histórico.
- [06 GC Pack Optimization](./06%20GC%20Pack%20Optimization): Otimize um repositório grande com git gc --aggressive, git repack e pack-refs.
- [07 Alternates Sharing](./07%20Alternates%20Sharing): Configure Git Alternates para compartilhar object stores entre repositórios.
- [08 Partial Clone](./08%20Partial%20Clone): Configure partial clone com filtros de blob e tree para repositórios gigantescos.
- [09 Git Protocol](./09%20Git%20Protocol): Implemente um servidor Git minimalista usando git-upload-pack e git-receive-pack via SSH.
- [10 Git Daemon](./10%20Git%20Daemon): Configure o git daemon para servir repositórios via protocolo Git nativo.
- [11 Virtual Filesystem](./11%20Virtual%20Filesystem): Explore o GVFS (Git Virtual File System) para repositórios de escala de enerprise.
- [12 Commit Graph](./12%20Commit%20Graph): Use e mantenha o commit-graph file para acelerar traversal de histórico.
- [13 Multi Pack Index](./13%20Multi%20Pack%20Index): Configure o multi-pack-index (MIDX) para pesquisas mais rápidas em repositórios grandes.
- [14 Feature Reachability](./14%20Feature%20Reachability): Implemente um script que encontra todos os commits que introduziram uma feature específica.
- [15 Git Cinnabar](./15%20Git%20Cinnabar): Use git-cinnabar para interoperar com repositórios Mercurial.
- [16 Git Workspace](./16%20Git%20Workspace): Configure git worktrees com sparse-checkout para uma estratégia monorepo escalável.
- [17 Fsck Repair](./17%20Fsck%20Repair): Use git fsck para detectar corrupção e repare o repositório com ferramentas de baixo nível.
- [18 Hooks Framework](./18%20Hooks%20Framework): Construa um framework de hooks Git reutilizáveis instalável via npm ou script.
- [19 Semantic Versioning Ci](./19%20Semantic%20Versioning%20Ci): Configure um pipeline completo de semantic versioning com changelogs automáticos.
- [20 Git Annex](./20%20Git%20Annex): Use git-annex para gerenciar arquivos grandes distribuídos em múltiplos backends.
- [21 Merge Queue](./21%20Merge%20Queue): Configure o Merge Queue do GitHub para serializar PRs e evitar the merge train problem.
- [22 Stacked Diffs](./22%20Stacked%20Diffs): Implemente um workflow de Stacked Diffs (como no Facebook) usando git-stack ou Graphite.
- [23 Bisect Regression Suite](./23%20Bisect%20Regression%20Suite): Construa uma suíte de testes de regressão automáticos para uso com git bisect.
- [24 Git Credential Helper](./24%20Git%20Credential%20Helper): Implemente um Git Credential Helper customizado para autenticação em sistemas internos.
- [25 Repository Mining](./25%20Repository%20Mining): Faça repository mining: extraia estatísticas, métricas de qualidade e hotspots do histórico Git.
- [26 Repo Archaeology](./26%20Repo%20Archaeology): Faça arqueologia de repositório: rastreie a origem de uma decisão de arquitetura no histórico.
- [27 Git Split Monolith](./27%20Git%20Split%20Monolith): Divida um monolito Git em múltiplos repositórios com histórico preservado usando filter-repo.
- [28 Signed Pushes](./28%20Signed%20Pushes): Configure verificação de assinatura no lado do servidor para bloquear pushes não assinados.
- [29 Git Attributes Avançado](./29%20Git%20Attributes%20Avançado): Use .gitattributes para normalização de line endings, linguist overrides e merge strategies por arquivo.
- [30 Git At Scale](./30%20Git%20At%20Scale): Pesquise e documente como empresas (Google, Facebook, Microsoft) escalam o Git para repositórios de bilhões de objetos.
